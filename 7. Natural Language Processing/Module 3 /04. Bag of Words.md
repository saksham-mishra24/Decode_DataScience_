# 💻 Scene 5 — Code Example

---

```python id="bow_code"
from sklearn.feature_extraction.text import CountVectorizer

# sentences
sentences = [
    "I love AI",
    "I love ML",
    "AI is powerful"
]

# vectorizer
vectorizer = CountVectorizer()

# convert text → vectors
X = vectorizer.fit_transform(sentences)

# vocabulary
print(vectorizer.get_feature_names_out())

# vectors
print(X.toarray())
```

The Bag of Words is a fundamental technique in Natural Language Processing (NLP) for converting text into a numerical representation suitable for machine learning algorithms.

Step 1: Tokenization - splitting each sentence into individual words
Step 2: Create Vocabulary - list of unique words
Step 3: Remove stop words from Vocabulary
Step 4: Count Word Occurrences
