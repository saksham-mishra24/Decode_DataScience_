# 💻 Scene 7 — Code: Basic Stemming

```python id="stem_basic_code"
from nltk.stem import PorterStemmer

stemmer = PorterStemmer()

words = ["playing", "studies", "amazing", "connected"]

stemmed_words = []

for w in words:
    stemmed_words.append(stemmer.stem(w))

print(stemmed_words)
```

---

### Output

```text id="stem_output"
['play', 'studi', 'amaz', 'connect']
```
