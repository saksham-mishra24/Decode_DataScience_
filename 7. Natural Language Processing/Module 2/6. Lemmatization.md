# 💻 Scene 6 — Code: Basic Lemmatization

```python
from nltk.stem import WordNetLemmatizer

lemmatizer = WordNetLemmatizer()

words = ["playing", "running", "better"]

lemmatized = [lemmatizer.lemmatize(w) for w in words]

print(lemmatized)
```

# ✅ Scene 8 — Correct Way (with POS)

---

```python
from nltk.stem import WordNetLemmatizer

lemmatizer = WordNetLemmatizer()

words = ["playing", "running", "better"]

lemmatized = [lemmatizer.lemmatize(w, pos='v') for w in words]

print(lemmatized)
```

---

### Output

```text
['play', 'run', 'better']
```

---

---

# 🧠 Scene 9 — POS Values Cheat Sheet

---

```text id="pos_values"
'n' → noun  
'v' → verb  
'a' → adjective  
'r' → adverb  
```

---

---

# 🔄 Scene 10 — Full Pipeline Example

---

```python
import nltk
from nltk.stem import WordNetLemmatizer
from nltk.corpus import wordnet

lemmatizer = WordNetLemmatizer()

sentence = "The boys are running better than before"

words = sentence.lower().split()

lemmatized = []

for word in words:
    lemmatized.append(lemmatizer.lemmatize(word, pos='v'))

print(lemmatized)
```

---

### Output

```text
['the', 'boys', 'are', 'run', 'better', 'than', 'before']
```
