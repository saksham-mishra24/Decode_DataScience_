CH 00

Introduction to Text Preprocessing

Why raw text is a mess — and how we clean it up

🎯

Learning Goal

Understand what text preprocessing is, why it is needed before training any machine learning model, and what all the steps are at a high level.

🧠

What is Text Preprocessing?

When you collect text data from the internet (websites, Twitter, WhatsApp, reviews etc.), that text is raw and messy. It contains:

  • HTML tags like <b>, <p>
  • Links (URLs)
  • Spelling mistakes
  • Short forms like GN, ASAP, IMHO
  • Emojis 😊 🔥
  • Punctuation marks like . ! ? , ;

Machine learning models cannot understand this messy text. We need to clean and prepare it first. This cleaning process is called Text Preprocessing.

🏺 Real-Life Analogy

Imagine you got vegetables from the market — they have mud, extra leaves, and wrappers on them. Before cooking, you wash, peel, and cut them. Text preprocessing is exactly this — washing and preparing your data before cooking (training) it.

📋

Two Types of Text Preprocessing

✅ Basic (This Course)
  • Lowercasing
  • Remove HTML tags
  • Remove URLs
  • Remove Punctuation
  • Chat word treatment
  • Spelling correction
  • Stop word removal
  • Emojis handling
  • Tokenization
  • Stemming & Lemmatization
🔬 Advanced (Future Course)

  • If your data has no HTML (e.g. a book), skip HTML removal
  • If your data has no URLs (e.g. newspaper), skip URL removal

You will develop this judgment through practice. For now, learn all steps — decide which to apply later.

CH 01

Lowercasing

Make all letters small — the simplest and first step

🎯

Learning Goal

Convert all characters in a text document to lowercase. Understand why this removes unnecessary complexity from your model.

🧠

The Problem

In English, sentences start with a capital letter. So the word "Basically" (at the start of a sentence) and "basically" (in the middle) look different to Python — even though they mean the same thing.

❌ Before (Python sees these as 2 different words)
"Basically" → word 1
"basically" → word 2
✅ After Lowercasing (now they are the same)
"basically" → word 1
"basically" → same word

This extra confusion slows down and confuses your model. Lowercasing removes this problem instantly.

🏺 Analogy

Imagine a register where names are written in many different styles: "RAVI", "Ravi", "ravi". If you search for "ravi" — you miss the others. Lowercasing ensures everything is in one consistent style.

💻

Code — Single String

PYTHON
# A simple sentence with mixed case
text = "One day I was Walking in the PARK and it was Basically amazing"

# Convert everything to lowercase
text_lower = text.lower()

print(text_lower)
# Output: "one day i was walking in the park and it was basically amazing"

Explanation: Python's built-in .lower() method converts every character to its lowercase version. One line of code, zero effort.

💻

Code — Full Dataset (50,000 Movie Reviews)

PYTHON
# df is our pandas DataFrame
# 'review' is the column with movie review text

df['review'] = df['review'].str.lower()

# .str.lower() applies .lower() to every row automatically

Why .str.lower()? When working with a full pandas column, you use .str.lower() — the .str accessor lets you apply string functions to all rows at once without writing a loop.

CH 02

Remove HTML Tags

Strip browser formatting codes from scraped web data

🎯

Learning Goal

Understand what HTML tags are and why they must be removed from text data before NLP tasks.

🧠

What Are HTML Tags?

HTML tags are special codes used in websites to tell the browser how to display content. For example:

  • <b>Hello</b> → makes text bold
  • <p>Some text</p> → creates a paragraph
  • <a href="...">Click</a> → creates a link

When you scrape text from a website (like IMDB reviews), these HTML tags come along with the text. Your ML model sees them as meaningless symbols — they add confusion without contributing any meaning.

❌ Raw Scraped Text
<html><body>
<p>This movie was <b>amazing</b>!
<a href="...">Read more</a>
</p></body></html>
✅ After HTML Removal

This movie was amazing!
Read more

💻

Code — Remove HTML Tags Using Regex

PYTHON
import re   # re = Regular Expressions library

def remove_html_tags(text):
    # Pattern: find anything between < and >, remove it
    pattern = r'<.*?>'
    return re.sub(pattern, '', text)

# Test it
sample = "<html><body><p>This is <b>great</b> text!</p></body></html>"
print(remove_html_tags(sample))
# Output: "This is great text!"

What is re.sub()? It means "substitute" — replace the pattern with something (here: empty string '' = delete it).

Pattern r'<.*?>' means: Find anything that starts with <, has any characters, and ends with >. Remove it.

💻

Code — Apply to Full Dataset

PYTHON
# Apply the function to every row in the 'review' column
df['review'] = df['review'].apply(remove_html_tags)

# .apply() passes each row value into the function one by one
⚠️ Common Mistake

You do NOT need to understand every regex symbol right now. Just know: copy this function, use it in your project, and learn regex separately. Many online tools like regex101.com can help you test patterns visually.

CH 03

Remove URLs

Strip web links from social media and chat data

🧠

Why Remove URLs?

When you collect text from Twitter, WhatsApp, or other social media, users often share links inside their messages. For example:

EXAMPLE TEXT
"Great article! Check this out: https://www.example.com/article123
Also see: http://news.site.com/today"

These URLs do not contribute to the meaning in tasks like sentiment analysis or text classification. They confuse the model and add noise.

💻

Code — Remove URLs

PYTHON
import re

def remove_urls(text):
    # Pattern handles: https://, http://, www., and plain links
    pattern = r'https?://\S+|www\.\S+'
    return re.sub(pattern, '', text)

# Test with different URL formats
text1 = "Visit https://example.com for more info"
text2 = "Check http://news.com/article"
text3 = "Go to www.google.com now"

print(remove_urls(text1))  # "Visit  for more info"
print(remove_urls(text2))  # "Check "
print(remove_urls(text3))  # "Go to  now"

Pattern breakdown:

  • https?:// — matches http:// or https://
  • \S+ — matches everything that is not a space (the rest of the URL)
  • | — means "OR"
  • www\.\S+ — matches links starting with www.

CH 04

Remove Punctuation

Clean out dots, commas, exclamation marks and more

🧠

What is Punctuation?

Punctuation marks are symbols like: . period , comma ! exclamation ? question ; semicolon : colon " quote

Python's string library has all of them pre-listed. You don't need to type each one manually.

🧠

Two Reasons to Remove Punctuation

Reason 1 — Tokenizer may treat punctuation as a separate word:

❌ With Punctuation
"Hello, how are you?"

After splitting →
["Hello,", "how", "are", "you?"]
(comma and ? create extra tokens)
✅ Without Punctuation
"Hello how are you"

After splitting →
["Hello", "how", "are", "you"]
(clean and simple)

Reason 2 — Same word becomes two different words:

If "hello" appears once normally and once as "hello!" — your model thinks these are two DIFFERENT words. This creates confusion and harms accuracy.

💻

Code — Method 1 (Simple, but Slow)

PYTHON
import string

# Get all punctuation marks (Python already knows them)
print(string.punctuation)
# !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~

def remove_punctuation_slow(text):
    for char in string.punctuation:
        text = text.replace(char, '')
    return text

# Works but SLOW on large datasets
💻

Code — Method 2 (Fast — Use This!)

PYTHON
import string

def remove_punctuation(text):
    # str.maketrans creates a "translation table"
    # It maps each punctuation character → None (delete)
    return text.translate(str.maketrans('', '', string.punctuation))

# Test
text = "Hello, World! How are you? I'm fine."
print(remove_punctuation(text))
# Output: "Hello World How are you Im fine"

Why is Method 2 faster? Method 1 loops through every punctuation mark one by one. Method 2 uses a translation table — Python processes all replacements in one internal operation. On 50,000 reviews, Method 2 is approximately 3x faster.

💻

Apply to Dataset

PYTHON
df['tweet'] = df['tweet'].apply(remove_punctuation)

CH 05

Chat Word Treatment

Expand short forms (GN → Good Night, ASAP → As Soon As Possible)

🧠

The Problem with Short Forms

In messaging apps (WhatsApp, Twitter, SMS), people use abbreviations to type faster:

Short FormFull Form
GNGood Night
ASAPAs Soon As Possible
IMHOIn My Humble Opinion
FYIFor Your Information
brbBe Right Back
tbhTo Be Honest

Your ML model does not know what "GN" means. It treats it as an unknown word. This causes mistakes in understanding.

🧠

When Do You Need This Step?

Only when your data comes from:

  • Social media (Twitter, Instagram)
  • Messaging apps (WhatsApp, Telegram)
  • Chat support systems
  • SMS data

For newspaper articles or formal documents, skip this step.

💻

Code — Chat Word Expander

PYTHON
# Dictionary: short form → full form
chat_words = {
    "GN": "Good Night",
    "gn": "Good Night",
    "ASAP": "As Soon As Possible",
    "IMHO": "In My Humble Opinion",
    "FYI": "For Your Information",
    "brb": "Be Right Back",
    "tbh": "To Be Honest",
    # ... (hundreds more in a real dictionary file)
}

def expand_chat_words(text):
    words = text.split()          # Split text into words
    expanded = []
    for word in words:
        if word in chat_words:       # Is this a known short form?
            expanded.append(chat_words[word])  # Replace with full form
        else:
            expanded.append(word)   # Keep the word as is
    return ' '.join(expanded)      # Join words back into a sentence

# Test
print(expand_chat_words("IMHO he is the best"))
# Output: "In My Humble Opinion he is the best"
🏺 Analogy

Imagine you receive a letter with the abbreviation "w/o" — you know it means "without". But a computer reading it doesn't know that. The chat word dictionary is like a translation guide that teaches the computer all these short forms.

✍️

Practice Tasks

🌍 Real-Life Example

A company wants to analyze customer support chat logs. Customers write: "pls fix asap, brb checking my bill tbh this is v bad." Without expansion, the model sees gibberish. Spelling Correction

Fix typos and misspelled words automatically

🧠

Why Correct Spelling?

Users on social media and review sites make spelling mistakes. For example:

❌ With Typos
"please reed the notbook entries"
✅ Corrected
"please read the notebook entries"

notbook and notebook look different to Python — they will be treated as two different words. This adds unnecessary complexity to your model.

💻

Code — Using textblob

PYTHON
# Install first: pip install textblob
from textblob import TextBlob

# Incorrect text with many typos
incorrect_text = "Ceertain conditionas duriing seveal ggenerations"

# Create a TextBlob object
blob = TextBlob(incorrect_text)

# .correct() fixes spelling automatically
corrected = blob.correct()

print(corrected)
# Output: "Certain conditions during several generations"
⚠️

Limitations of Spelling Correction

  • Works well for common English words
  • May struggle with domain-specific words (medical terms, regional words, brand names)
  • May struggle with slang or intentional misspellings
  • Can be slow on very large datasets

Other libraries: pyspellchecker autocorrect symspellpy

CH 07

Removing Stop Words

Remove common filler words that add no meaning

🧠

What Are Stop Words?

Stop words are very common words in English that are used to build sentences — but they don't carry much meaning by themselves.

Examples: the a an is are was were I my for of in to that

❌ With Stop Words
"The movie was not very
good for me at all"
✅ Stop Words Removed
"movie good"

(Key meaning preserved!)
🏺 Analogy

In a telegram (old messaging), you paid per word — so people wrote only important words: "SEND MONEY URGENT" instead of "Please send me some money as it is very urgent." Stop word removal is like writing a telegram — keep only what matters.

💻

Code — Remove Stop Words using NLTK

PYTHON
import nltk
from nltk.corpus import stopwords

# Download the list of stop words (only needed once)
nltk.download('stopwords')

# Get English stop words list
stop_words = set(stopwords.words('english'))

def remove_stopwords(text):
    words = text.split()
    filtered = [w for w in words if w not in stop_words]
    return ' '.join(filtered)

# Test
text = "I am going to the market and I will buy some vegetables"
print(remove_stopwords(text))
# Output: "going market buy vegetables"

# Apply to entire dataset
df['review'] = df['review'].apply(remove_stopwords)
⚠️

When NOT to Remove Stop Words

Do NOT remove stop words when doing Parts of Speech (POS) Tagging. Stop words help determine grammar roles, so removing them would break POS analysis.

Also be careful with sentiment with negation: "This is not good" — if you remove "not" (a stop word), it becomes "This is good" — completely opposite meaning!

CH 08

Handling Emojis

Remove or convert emojis to readable text

🧠

The Emoji Problem

Modern text data (especially from social media) contains many emojis. ML algorithms cannot understand emojis — they see them as unknown symbols. You have two choices:

Option 1 — Remove Emojis

Delete all emojis from the text. Simple and fast. Best when emojis are rare in your data.

Option 2 — Replace with Meaning

Convert 😊 → "smiling face". Keeps the emotional content. Better for sentiment analysis.

💻

Code — Option 1: Remove Emojis

PYTHON
import re

def remove_emojis(text):
    # Unicode patterns for different emoji categories
    emoji_pattern = re.compile("["
        u"\U0001F600-\U0001F64F"  # Emoticons (😀😂🥹)
        u"\U0001F300-\U0001F5FF"  # Symbols & pictographs
        u"\U0001F680-\U0001F6FF"  # Transport & map symbols
        u"\U0001F1E0-\U0001F1FF"  # Flags
    "]+", flags=re.UNICODE)
    return emoji_pattern.sub(r'', text)

# Test
print(remove_emojis("I love this movie 😍🔥❤️"))
# Output: "I love this movie "
💻

Code — Option 2: Replace Emoji with Meaning

PYTHON
# Install first: pip install emoji
import emoji

text = "I love this movie 😍 it was fire 🔥"

# demojize() replaces each emoji with its text description
result = emoji.demojize(text)
print(result)
# Output: "I love this movie :smiling_face_with_heart-eyes: it was fire :fire:"

When to use which? If you're doing sentiment analysis, use Option 2 — emoji meaning carries emotion. For other tasks, Option 1 is simpler.

✍️

CH 09

Tokenization

The most important step — breaking text into smaller pieces

🎯

Learning Goal

Understand what tokenization is, why it is the most critical preprocessing step, and which library gives the best results.

🧠

What is Tokenization?

Tokenization is the process of breaking a text document into smaller pieces called tokens.

Tokens can be:

  • Words → "I am going" → ["I", "am", "going"]
  • Sentences → "I am fine. How are you?" → ["I am fine.", "How are you?"]

Word tokenization is used most commonly.

🧠

Why Is Tokenization Important?

Before your ML model can analyze text, it needs numbers — not words. To convert words to numbers, you first need to split text into individual words (tokens). Wrong tokenization → wrong features → bad model.

🏺 Analogy

Imagine you want to count how many times each ingredient appears in a recipe. First you must separate each ingredient into its own item. Tokenization is that separation step for text.

Real Example: "I am new in New Delhi" — how many unique words?

Answer: 5 unique words — because "new" (adjective) and "New" in "New Delhi" are DIFFERENT uses. Smart tokenization understands "New Delhi" as a single unit.

⚠️

Challenges in Tokenization

ChallengeExampleCorrect Handling
Currency symbols$20["$", "20"]
Units5km["5", "km"]
Contractionslet's["let", "'s"]
AbbreviationsU.S.["U.S."] (keep together)
Email IDsuser@gmail.comKeep as one unit
HyphensNew York["New", "York"] or ["New York"]
💻

Method 1 — Simple Split (Basic)

PYTHON
sentence = "I am going to the market"

# Split by space — simplest method
tokens = sentence.split()
print(tokens)
# Output: ['I', 'am', 'going', 'to', 'the', 'market']

# Problem: fails with punctuation
s2 = "I am going to Delhi!"
print(s2.split())
# Output: ['I', 'am', 'going', 'to', 'Delhi!']  ← Delhi! has ! attached
💻

Method 2 — NLTK (Better)

PYTHON
import nltk
from nltk.tokenize import word_tokenize, sent_tokenize

# Word-level tokenization
text = "I am going to visit Delhi! It is a great city."
print(word_tokenize(text))
# ['I', 'am', 'going', 'to', 'visit', 'Delhi', '!', 'It', 'is', 'a', 'great', 'city', '.']
# Notice: Delhi and ! are now SEPARATE — much better!

# Sentence-level tokenization
print(sent_tokenize(text))
# ['I am going to visit Delhi!', 'It is a great city.']
💻

Method 3 — spaCy (Best — Recommended)

PYTHON
# Install: pip install spacy
# Download model: python -m spacy download en_core_web_sm
import spacy

nlp = spacy.load('en_core_web_sm')  # Load English language model

text = "I have a Ph.D. in CS. We are here to help. Mail at user@gmail.com"
doc = nlp(text)

# Get all tokens
tokens = [token.text for token in doc]
print(tokens)
# Correctly handles: Ph.D. stays together, email stays together!

Why spaCy is best:

  • Handles edge cases like Ph.D., U.S., email addresses, currency
  • Built-in linguistic intelligence
  • Used by professionals in production systems
📊

Comparison: Which Method to Use?

MethodSpeedAccuracyBest For
.split()FastestLowVery simple, clean text
NLTKFastMediumMost standard projects
spaCyMediumBestProduction / complex text

CH 10

Stemming

Reduce words to their root form (fast but rough)

🧠

Understanding Inflection First

In English, the same word can appear in many forms — this is called inflection. For example:

Base WordInflected Forms
walkwalked, walking, walks, walker
dodid, done, doing, doable
movemoving, moved, moves, movement

To your ML model, "walking" and "walked" look like completely different words. This adds unnecessary complexity. Both should map to the same root: "walk".

🧠

What is Stemming?

Stemming is the process of cutting off prefixes and suffixes from a word to get its root form (called the stem).

🏺 Analogy

Imagine all variants of a word as different flowers from the same plant. Stemming cuts the flowers and gets to the stem. The stem may not be a real word — but all flower variants point to it.

Important: The stem may NOT be a real English word. For example: "probably" → "probabl". This is okay for machine use, but NOT good to show to users.

💻

Code — Porter Stemmer (NLTK)

PYTHON
from nltk.stem import PorterStemmer

ps = PorterStemmer()

def stem_words(text):
    words = text.split()
    stemmed = [ps.stem(w) for w in words]
    return ' '.join(stemmed)

# Test
text = "walking walked walks walker"
print(stem_words(text))
# Output: "walk walk walk walker"

# Watch out for imperfect results!
print(ps.stem("probably"))   # → "probabl"  (not a real word!)
print(ps.stem("movies"))     # → "movi"    (not a real word!)
print(ps.stem("history"))    # → "histori" (not a real word!)
🧠

Where is Stemming Most Useful?

Stemming is most useful in Information Retrieval Systems — search engines.

Example: If you search Google for "fishing", you also want results about "fish" and "fishes". Stemming groups all these together, so you get better search results.

How Lemmatization Works

Lemmatization uses a lexical dictionary called WordNet — a database that stores English words and their relationships. When you call lemmatize("walking"), it searches WordNet and returns the lemma (dictionary form): "walk".

Because it searches a dictionary, it is slower — but the output is always a valid English word.

💻

Code — WordNet Lemmatizer (NLTK)

PYTHON
from nltk.stem import WordNetLemmatizer
from nltk.tokenize import word_tokenize
import string

wnl = WordNetLemmatizer()

sentence = "The stripes are clearly visible on running horses"

# Tokenize the sentence
tokens = word_tokenize(sentence)

# Remove punctuation and lemmatize each word
result = []
for token in tokens:
    if token not in string.punctuation:
        # pos='v' means: treat as a verb (better for action words)
        lemma = wnl.lemmatize(token, pos='v')
        result.append((token, lemma))

for original, lemma in result:
    print(f"{original} → {lemma}")

# The      → The
# stripes  → stripe
# are      → be
# clearly  → clearly
# visible  → visible
# running  → run
# horses   → horse

Why specify pos='v'? POS = Part of Speech. If you specify verb, the lemmatizer uses verb forms. Without this, results may not change. For best results, always specify POS.

📊

Final Decision Guide

❓ Will users see the output?

→ YES → Use Lemmatization (output is real English)

→ NO → Use Stemming (faster, good enough for model)

❓ Is speed very important on huge data?

→ YES → Use Stemming

→ NO → Use Lemmatization for better quality

🌍 Real-Life Example

Google Translate uses lemmatization — when it translates "running", "ran", "runs" — it first finds the root word "run" from the dictionary and then translates accordingly. This is why Google Translate understands all verb forms of a word.
