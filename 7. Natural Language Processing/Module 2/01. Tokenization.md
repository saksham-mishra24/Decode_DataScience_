# 💻 Scene 9 — Code Example (Simple)

```python id="tok_code_1"
from tensorflow.keras.preprocessing.text import Tokenizer

# sentences
texts = [
    "I love AI",
    "AI is amazing"
]

# tokenizer object
tokenizer = Tokenizer()

# learn vocabulary
tokenizer.fit_on_texts(texts)

# convert text to numbers
sequences = tokenizer.texts_to_sequences(texts)

print(sequences)
```
