# 💻 Step 1 — Basic Dependency Parsing (English vs Hindi)

Using spaCy

```python
# 👉 spaCy import
import spacy

# 👉 English model load (accurate for English)
nlp_en = spacy.load("en_core_web_sm")

# 👉 Multilingual model load (Hindi ke liye fallback, but weak)
# NOTE: Ye Hindi ke liye properly trained nahi hai
nlp_hi = spacy.load("xx_ent_wiki_sm")

# 👉 English sentence
text_en = "Ram loves Sita"

# 👉 Hindi (actually Hinglish) sentence
text_hi = "Ram Sita se pyaar karta hai"

# 👉 Process both texts
doc_en = nlp_en(text_en)
doc_hi = nlp_hi(text_hi)

print("---- English ----")

# 👉 English parsing (reliable)
for token in doc_en:
    # token.text  → word
    # token.dep_  → grammatical role
    # token.head.text → kis word se connected
    print(token.text, token.dep_, token.head.text)

print("\n---- Hindi ----")

# 👉 Hindi parsing (unreliable with this model)
for token in doc_hi:
    print(token.text, token.dep_, token.head.text)
```

---

## 🧠 Insight

* English me:

  * word order strong signal hai
* Hindi me:

  * model struggle karega (weak training)

👉 Same code → different performance 😐

# 💻 Step 4 — Real Multilingual Pipeline (Simplified)

```python
# 👉 Required imports
from langdetect import detect
import spacy

# 👉 Models load (assume installed already)
nlp_en = spacy.load("en_core_web_sm")
nlp_hi = spacy.load("xx_ent_wiki_sm")  # weak for Hindi

# 👉 Function jo text process karega
def process_text(text):
    # 👉 Step 1: Language detect karna
    lang = detect(text)

    # 👉 Step 2: Language ke basis par model choose karna
    if lang == "en":
        doc = nlp_en(text)   # English ke liye strong model
    else:
        doc = nlp_hi(text)   # Hindi/mixed ke liye weak fallback

    # 👉 Step 3: Har word ka dependency print karna
    for token in doc:
        print(token.text, token.dep_, token.head.text)
```
