# 💻 Step 4 — Code (NLTK NER)

---

```python id="ner_code1"
import nltk
from nltk.tokenize import word_tokenize
from nltk import pos_tag, ne_chunk

text = "Elon Musk founded Tesla in California"

tokens = word_tokenize(text)
tags = pos_tag(tokens)

entities = ne_chunk(tags)

print(entities)
```
