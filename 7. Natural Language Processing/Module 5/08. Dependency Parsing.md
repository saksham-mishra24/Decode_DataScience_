# 🧠 Step 1 — Dependency Parsing kya hai?

👉 Sentence ko **relations ke network** me convert karta hai

* Har word kisi na kisi word pe depend karta hai
* Ek main word hota hai → ROOT

---

## Example:

👉 "Ram loves Sita"

---

## Output:

* loves → ROOT
* Ram → subject of loves
* Sita → object of loves

# 🧠 Step 3 — Important Terms

| Term      | Meaning               |
| --------- | --------------------- |
| ROOT      | main word             |
| head      | jispe depend kar raha |
| dependent | jo depend kar raha    |
| relation  | connection type       |

---

# 🧠 Step 4 — Common Relations

| Relation | Meaning            |
| -------- | ------------------ |
| nsubj    | subject            |
| dobj     | direct object      |
| amod     | adjective modifier |
| prep     | preposition        |

---

## Example:

👉 "Virat Kohli scored 100 runs"

* scored → ROOT
* Virat Kohli → nsubj
* runs → dobj
* 100 → number modifier

# 💻 Step 5 — Code (spaCy)

```python id="dep2"
# 👉 spaCy import kar rahe hain (modern NLP library)
import spacy

# 👉 English language model load kar rahe hain
# NOTE: Agar ye model install nahi hai to error aayega
nlp = spacy.load("en_core_web_sm")

# 👉 Input sentence
doc = nlp("Virat Kohli scored 100 runs")

# 👉 Har word (token) ke liye loop chala rahe hain
for token in doc:
    # token.text  → word khud
    # token.dep_  → word ka role (subject, object, etc.)
    # token.head.text → ye word kis word se connected hai
    print(token.text, token.dep_, token.head.text)
```

---

## Output samjho:

* Virat → nsubj → scored
* Kohli → compound → Virat
* scored → ROOT
* runs → dobj → scored
* 100 → nummod → runs

👉 pura relation map mil gaya
