# 💻 Step 6 — Code (POS Tagging using NLTK)

---

```python id="syn_code1"
import nltk
from nltk.tokenize import word_tokenize
from nltk import pos_tag

text = "The cat eats fish"

tokens = word_tokenize(text)
tags = pos_tag(tokens)

print(tags)
```
