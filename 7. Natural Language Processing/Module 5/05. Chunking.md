# 🧠 Step 1 — Chunking kya hai?

👉 Chunking = **words ko meaningful groups me todna**

* POS: individual words
* Chunking: word groups

---

## Example:

Sentence:
👉 "Virat Kohli scored a brilliant century"

### POS:

* Virat → NNP
* Kohli → NNP
* scored → VBD
* a → DT
* brilliant → JJ
* century → NN

---

### Chunking Output:

* [Virat Kohli] → Noun Phrase (NP)
* [scored] → Verb
* [a brilliant century] → Noun Phrase (NP)

# 🧠 Step 2 — Chunk Types

## 🔹 1. Noun Phrase (NP)

👉 Subject / object

Example:

* "the big house"
* "Virat Kohli"

---

## 🔹 2. Verb Phrase (VP)

👉 action part

Example:

* "is playing"
* "has scored"

---

## 🔹 3. Prepositional Phrase (PP)

👉 location/time relation

Example:

* "in Delhi"
* "on Monday"

# 💻 Step 3 — Code (NLTK Chunking)

```python
# Natural Language Toolkit (NLTK) import kar rahe hain
import nltk

# 👉 First time run karte waqt ye downloads zaroori hain
# Ye language models download karte hain jo tokenize aur tagging ke liye chahiye
nltk.download('punkt')  # word_tokenize ke liye
nltk.download('averaged_perceptron_tagger')  # POS tagging ke liye

# 👉 Ye input sentence hai jisko process karna hai
sentence = "Virat Kohli scored 100 runs in Delhi"

# 👉 Step 1: Sentence ko words (tokens) me todna
tokens = nltk.word_tokenize(sentence)

# 👉 Step 2: Har word ka part-of-speech (POS) tag nikalna
# Jaise noun, verb, etc.
tags = nltk.pos_tag(tokens)

# 👉 Step 3: Grammar rules define karna (chunking ke liye)
grammar = """
# NP = Noun Phrase (jaise "Virat Kohli", "100 runs")
NP: {<DT>?<JJ>*<NN.*>}

# PP = Prepositional Phrase (jaise "in Delhi")
PP: {<IN><NP>}

# VP = Verb Phrase (jaise "scored 100 runs in Delhi")
VP: {<VB.*><NP|PP>*}
"""

# 👉 Step 4: Parser banana jo grammar rules apply karega
cp = nltk.RegexpParser(grammar)

# 👉 Step 5: Tagged words par grammar apply karke tree banana
tree = cp.parse(tags)

# 👉 Step 6: Text format me tree print karna
print(tree)

# 👉 Step 7: Graphical tree show karna (GUI window open hogi)
# NOTE: Ye har system par kaam nahi karta (GUI dependency hoti hai)
try:
    tree.draw()
except:
    print("Tree draw nahi ho paya (GUI support nahi hai).")
    print("Alternative view:")
    print(tree.pformat())
```

Tree structure banega:

* NP (Virat Kohli)
