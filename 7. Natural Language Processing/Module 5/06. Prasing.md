# 🧠 Step 1 — Parsing kya hai?

👉 Parsing = **sentence ka complete tree structure banana**

* kaun subject hai
* kaun object hai
* kaun kis se connected hai

---

## Example:

Sentence:
👉 "Ram loves Sita"

---

## Parsed Structure:

* Ram → Subject
* loves → Verb
* Sita → Object

---

# 🧠 Step 2 — Tree Representation

Parsing output = **Tree 🌳**

```
        S
      /   \
    NP     VP
    |     /  \
   Ram  loves Sita
```

👉 S = Sentence
👉 NP = Noun Phrase
👉 VP = Verb Phrase

---

# 🧠 Step 3 — Types of Parsing

## 🔹 1. Constituency Parsing

👉 Sentence ko phrases me todta hai

Example:

* NP (noun phrase)
* VP (verb phrase)

---

## 🔹 2. Dependency Parsing (More useful)

👉 Words ke relations batata hai

Example:

* loves → main verb
* Ram → subject of loves
* Sita → object of loves

---

Aman: Matlab relation samajh raha hai 😳

# 💻 Step 4 — Code Example (spaCy)

```python id="p9k2lx"
# 👉 spaCy import kar rahe hain (modern NLP library)
import spacy

# 👉 English model load karna (ye pre-trained hota hai)
# NOTE: Agar model install nahi hai to error aayega
nlp = spacy.load("en_core_web_sm")

# 👉 Input sentence
doc = nlp("Ram loves Sita")

# 👉 Har word (token) ke upar loop chala rahe hain
for token in doc:
    # token.text → actual word
    # token.dep_ → dependency (role in sentence)
    # token.head.text → ye word kis word se connected hai
    print(token.text, token.dep_, token.head.text)
```

---

## 🧠 Output samjho

* Ram → nsubj → loves
* loves → ROOT
* Sita → dobj → loves

👉 dependency relations mil gaye
