# 🧠 Step 1 — Syntactic Structure kya hota hai?

👉 Sentence me words ka order + relation

---

## English (SVO)

👉 Subject – Verb – Object

Example:
👉 "Ram eats mango"

---

## Hindi (SOV)

👉 Subject – Object – Verb

Example:
👉 "Ram aam khata hai"

---

Aman: Same meaning… order alag 😳

Riya: Exactly 🔥
👉 model confuse yahi hota hai

# 🧠 Step 5 — Dependency Differences

👉 English:

👉 Hindi:

* Sita → object

👉 position nahi… markers decide kar rahe hain
