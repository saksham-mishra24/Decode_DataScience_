# 📚 Learning Resources

Curated links to books, websites, courses, and tools for ML learning.

## 📖 Recommended Books

### Fundamentals
- **Introduction to Statistical Learning (ISLR)**
  - Best for: Practical ML concepts
  - Format: Free online PDF + interactive labs
  - URL: https://www.statlearning.com/

- **Python Machine Learning** by Sebastian Raschka
  - Best for: Hands-on Python implementations
  - Format: Physical book + online code examples

### Advanced Theory
- **The Elements of Statistical Learning (ESL)**
  - Best for: Deep theoretical foundation
  - Format: PDF available online
  - URL: https://hastie.su.domains/ElemStatLearn/

- **Deep Learning** by Goodfellow, Bengio, & Courville
  - Best for: Comprehensive deep learning theory
  - Format: Physical book + free online HTML
  - URL: https://www.deeplearningbook.org/

### Neural Networks
- **Neural Networks and Deep Learning** by Michael Nielsen
  - Best for: Intuitive explanations
  - Format: Free online book with visualizations
  - URL: http://neuralnetworksanddeeplearning.com/

## 🎯 Study Tips

### Effective Learning Sequence
1. **Watch** conceptual videos first (3Blue1Brown, StatQuest)
2. **Read** introductory articles
3. **Study** textbook/course material
4. **Code** implementations from scratch
5. **Experiment** with datasets
6. **Apply** to real problems

### Practice Strategies
- Implement algorithms from scratch
- Visualize your results
- Explain concepts to others
- Write blog posts about learning
- Participate in competitions
- Build projects

### Time Management
- Set consistent study schedule
- Focus on understanding over speed
- Review previous concepts regularly
- Take breaks to avoid burnout
- Join study groups
