# 💀 SCENE 11 — THE ERROR (HORROR MOMENT)

**Riya:**

```python
a = tf.random.normal((32, 10))
b = tf.random.normal((5, 10))

tf.matmul(a, b)  # ERROR ❌
```

---

**Aman (panics):**
Ye kyun crash ho gaya?? 😨

---

**Riya (intense):**
👉 Shape mismatch

---

## 🎯 Simple samajh

Matrix multiply ke rule:

👉 inner numbers match hone chahiye

---

### ❌ Wrong

```python
(32,10) × (5,10)
```

👉 10 ≠ 5 → ERROR 💥

---

### ✅ Correct

```python
(32,10) × (10,5)
```

👉 10 = 10 → works 😎
