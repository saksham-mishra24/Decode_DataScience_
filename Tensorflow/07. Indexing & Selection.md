# 🟢 SCENE 8 — `boolean_mask` (FILTER POWER ⚡)

**Riya:**

```python
mask = [True, False, True, False]

tf.boolean_mask(x, mask)
```

👉 Output:

```
[[10, 20],
 [50, 60]]
```

---

**Aman:**
Matlab condition based selection 😳

---

## 🎯 Real example

**Riya:**

```python
values = [10, 25, 30, 5]

mask = values > 20
```

👉 mask:

```
[False, True, True, False]
```

---

👉 result:

```
[25, 30]
```

---

**Aman:**
Filtering 😎
