# 💀 SCENE 3 — AXIS (THE MOST CONFUSING THING)

**Riya (serious):**
👉 AXIS = direction

---

## 🎯 Visualization

```
[[1, 2],
 [3, 4]]
```

---

👉 **axis=0 ↓ (upar se neeche)**

```
[1+3, 2+4] = [4, 6]
```

---

👉 **axis=1 → (left se right)**

```
[1+2, 3+4] = [3, 7]
```

---

**Aman (confused):**
Wait… axis=0 me rows collapse ho rahe hain? 😵

**Riya:**
YES 🔥

👉 Rule yaad rakh:

* axis=0 → rows collapse
* axis=1 → columns collapse

---

## 🎯 Real life analogy

**Riya:**
Soch tu classroom me hai 🏫

```
Students = rows  
Subjects = columns
```

---

👉 axis=0

👉 har subject ka total (vertical ↓)

---

👉 axis=1

👉 har student ka total (horizontal →)

---

**Aman (eyes wide):**
OHHHH 😳

**Riya:**


```

```

---

**Aman:**

---

* food
* travel
* rent

👉 sab add → total expense

---

## 🔥 DL use

```python

```

👉 total error

---

---

## 🔥 Axis ke saath

