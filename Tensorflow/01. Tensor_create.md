### 🔍 Micro-examples

👉 **Padding (gap fill karna)**

Soch tere paas messages hain:

* "Hi"
* "Hello bro"
* "Good morning"

Length sabki different 😵

Computer ko equal length chahiye

Toh:

```id="3d7m4y"
Hi → Hi 0 0 0
```

👉 Ye extra zeros = padding

---

👉 **Reset (fresh start)**

Game khel raha hai 🎮
Score = 150

New game → score = 0

👉 Ye reset hai

---

👉 **Starting state (initial condition)**

Soch race start kar raha hai 🏃‍♂️

Starting pe speed kya hoti hai?
👉 0

Model bhi start me kuch nahi jaanta
👉 zero se start karta hai

---

**Aman:**
OHHH 😳 zero actually important hai!

**Riya:**
Exactly 😏🔥
