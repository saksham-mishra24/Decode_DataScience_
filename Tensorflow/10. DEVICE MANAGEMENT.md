# ⚡ SCENE 8 — MEMORY KA GAME 🤯

## 🔹 `set_memory_growth`

---

**Aman:**
GPU memory ka kya scene hota hai? 🤔

---

**Riya:**

👉 Normally:

GPU bolta hai:

```
"main poori memory le leta hoon 😈"
```

---

## 🔥 Fix

```python
gpus = tf.config.list_physical_devices('GPU')

if gpus:
    tf.config.experimental.set_memory_growth(gpus[0], True)
```

---

## 🧠 Simple meaning

👉 GPU jitni zarurat ho utni hi memory lega

---

## 🎯 Beginner example

Socho:

* Total RAM = 10GB
* Tumhe sirf 2GB chahiye

👉 memory_growth = waste nahi karega

---
