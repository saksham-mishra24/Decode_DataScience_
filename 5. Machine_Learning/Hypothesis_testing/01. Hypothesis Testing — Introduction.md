# 🧠 Step 1 — First Understand the Word "Hypothesis"

A **hypothesis** simply means:

```
An assumption or a claim about something.
```

### Example

Suppose a teacher says:

```
Students in this school study more than 5 hours per day.
```

This is a **claim**.

We need to check if this claim is **true or not** using data.

That process is called:

```
Hypothesis Testing
```

---

# 🧠 Step 2 — Why Do We Need Hypothesis Testing?

In real life we hear many claims:

Example:

```
This medicine cures headache faster.
```

```
This new teaching method improves marks.
```

```
Students who sleep 8 hours perform better.
```

But we cannot just **believe claims without evidence**.

So we collect **data** and test them scientifically.

This scientific checking process is:

```
Hypothesis Testing
```

---

# 🧠 Step 3 — The Two Types of Hypothesis

In hypothesis testing there are **always two hypotheses**.

### 1️⃣ Null Hypothesis (H₀)

This means:

```
There is NO effect
There is NO change
Nothing special is happening
```

Think of it as the **default assumption**.

Example:

```
The new medicine does NOT work better.
```

---

### 2️⃣ Alternative Hypothesis (H₁ or Ha)

This means:

```
There IS an effect
There IS a difference
Something is happening
```

Example:

```
The new medicine works better.
```

---

# 🎯 Example — School Study Hours

Professor Arjun gives a simple example.

Claim:

```
Students study more than 5 hours per day.
```

We write hypotheses like this:

### Null Hypothesis

```
H₀ : Average study time = 5 hours
```

### Alternative Hypothesis

```
H₁ : Average study time > 5 hours
```

Now we collect data from students and test it.

---

# 🧠 Step 4 — Real Life Analogy (Court Example)

Professor Arjun explains with a famous analogy.

### In a court case:

A person is considered:

```
Innocent until proven guilty
```

So the default assumption is:

```
Person is innocent
```

This is like the **Null Hypothesis**.

Then evidence is collected.

If evidence is strong, we reject innocence.

Meaning:

```
The person is guilty
```

This is the **Alternative Hypothesis**.

---

# 🧠 Hypothesis Testing Logic

The process looks like this:

```
Step 1
Assume Null Hypothesis is true

Step 2
Collect sample data

Step 3
Check if data strongly disagrees with the null hypothesis

Step 4
If disagreement is large → Reject H₀
Else → Fail to reject H₀
```

Notice something important.

We never say:

```
H₀ is proven true
```

We only say:

```
Reject H₀
or
Fail to reject H₀
```

# 🤖 Milo Explains in Simple Language

Milo summarizes.

Hypothesis Testing is like asking:

```
Is the difference real?
Or is it just random luck?
```

For example:

If a coin shows:

```
Heads = 6
Tails = 4
```

That could just be **random chance**.

But if a coin shows:

```
Heads = 95
Tails = 5
```

Something is clearly **wrong with the coin**.

Hypothesis testing helps us **measure this scientifically**.
