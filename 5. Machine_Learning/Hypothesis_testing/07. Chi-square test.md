# 🧠 Step 1 — When Do We Use Chi-Square Test?

We use Chi-Square when data is **categorical**, meaning it belongs to **groups or categories**.

Examples:

```text
Male / Female
Yes / No
Product A / Product B / Product C
Smoker / Non-smoker
```

So Chi-Square answers questions like:

```text
Is gender related to product preference?
Is smoking related to lung disease?
Is education level related to income category?
```

---

# 🎯 Example Scenario

Professor Arjun gives an example.

A company wants to know:

```text
Does gender affect product preference?
```

They survey 100 people.

The results:

| Gender | Product A | Product B |
| ------ | --------- | --------- |
| Male   | 30        | 20        |
| Female | 10        | 40        |

This table is called a:

```text
Contingency Table
```

Now the question is:

```text
Are these differences real?
Or just random chance?
```

To test this we use the **Chi-Square Test**.

---

# 🧠 Step 2 — Hypotheses

For Chi-Square tests we write hypotheses like this.

### Null Hypothesis (H₀)

```text
There is NO relationship between the variables.
```

Example:

```text
Gender and product preference are independent.
```

---

### Alternative Hypothesis (H₁)

```text
There IS a relationship between the variables.
```

Example:

```text
Gender influences product preference.
```

---

# 🧠 Step 3 — Idea Behind Chi-Square

The Chi-Square test compares:

```text
Observed values
vs
Expected values
```

Observed values:

```text
Actual data collected
```

Expected values:

```text
Values we would expect if there were NO relationship
```

---

# 🎯 Example

Observed Table:

| Gender | A  | B  |
| ------ | -- | -- |
| Male   | 30 | 20 |
| Female | 10 | 40 |

Now we calculate what numbers we would expect **if gender had no effect**.

Those are the **expected values**.

---

# 📊 Chi-Square Formula

Professor Arjun writes the formula.

```text
χ² = Σ (O − E)² / E
```

Milo explains the symbols.

| Symbol | Meaning           |
| ------ | ----------------- |
| O      | Observed value    |
| E      | Expected value    |
| Σ      | Sum of all values |

So the formula calculates:

```text
How different the observed data is from expected data.
```

---

# 🧠 Interpretation

If the difference between **observed and expected values** is:

### Small

```text
Data fits the null hypothesis
```

So we:

```text
Fail to Reject H₀
```

---

### Large

```text
Data does NOT fit the null hypothesis
```

So we:

```text
Reject H₀
```

# 📊 Degrees of Freedom

Chi-Square tests also use **degrees of freedom**.

Formula:

```text
df = (rows − 1) × (columns − 1)
```

Example:

Table size:

```text
2 rows × 2 columns
```

So:

```text
df = (2 − 1)(2 − 1)
df = 1
```

Degrees of freedom help determine the **critical value** of χ².

# 🧪 Python Example — Chi-Square Test

Now let's implement this in Python.

---

# Step 1 — Import Libraries

```python
# Import numpy for creating arrays
import numpy as np

# Import chi-square test function
from scipy.stats import chi2_contingency
```

Explanation:

```text
numpy → helps create data tables
chi2_contingency → performs Chi-Square test
```

---

# Step 2 — Create Contingency Table

```python
# Data from survey

data = np.array([
    [30, 20],  # Male
    [10, 40]   # Female
])
```

Explanation:

```text
Rows → Gender
Columns → Product choice
```

---

# Step 3 — Perform Chi-Square Test

```python
# Perform chi-square test

chi2_stat, p_value, dof, expected = chi2_contingency(data)
```

This function returns:

| Variable  | Meaning                              |
| --------- | ------------------------------------ |
| chi2_stat | Chi-square statistic                 |
| p_value   | probability result happened randomly |
| dof       | degrees of freedom                   |
| expected  | expected values table                |

---

# Step 4 — Print Results

```python
print("Chi-Square Statistic:", chi2_stat)
print("P-value:", p_value)
print("Degrees of Freedom:", dof)
```

---

# Step 5 — Decision Rule

```python
alpha = 0.05

if p_value < alpha:
    print("Reject Null Hypothesis")
else:
    print("Fail to Reject Null Hypothesis")
```

Explanation:

```text
If p-value < 0.05
→ variables are related
```

# 🚀 Final Major Test in Hypothesis Testing

The last major test we should cover is:

```text
ANOVA (Analysis of Variance)
```

Why ANOVA is important:

```text
Z-test → compare 1 mean
T-test → compare 2 means
ANOVA → compare 3 or more means
```

Example:

```text
Comparing marks of students taught by
Method A, Method B, Method C
```

ANOVA is **extremely important in data science and experiments**.
