# 🧠 Step 1 — Remember the Hypotheses

Before understanding errors, recall:

### Null Hypothesis (H₀)

```text
Nothing special is happening
No difference exists
```

Example:

```text
H₀ : The medicine does NOT cure the disease
```

---

### Alternative Hypothesis (H₁)

```text
Something is happening
There is a difference
```

Example:

```text
H₁ : The medicine DOES cure the disease
```

---

# 🧠 Step 2 — Possible Decisions

After performing the test, we have two possible decisions.

```text
1. Reject H₀
2. Fail to Reject H₀
```

But reality can also be **two things**.

```text
1. H₀ is actually true
2. H₀ is actually false
```

So there are **4 possible outcomes**.

---

# 📊 Decision Table

| Reality  | Our Decision      | Result       |
| -------- | ----------------- | ------------ |
| H₀ True  | Fail to Reject H₀ | Correct      |
| H₀ True  | Reject H₀         | Type 1 Error |
| H₀ False | Reject H₀         | Correct      |
| H₀ False | Fail to Reject H₀ | Type 2 Error |

This table is **very important in statistics**.

---

# 🚨 Type 1 Error

Professor Arjun explains.

```text
Type 1 Error
= Rejecting the Null Hypothesis when it is actually TRUE
```

Symbol:

```text
α (alpha)
```

This is the **same α we saw earlier**.

---

# 🎯 Simple Example — Court Case

Recall the **court analogy**.

### Null Hypothesis

```text
The person is innocent
```

Now imagine the court decides:

```text
The person is guilty
```

But in reality:

```text
The person was innocent
```

This is:

```text
Type 1 Error
```

Meaning:

```text
Punishing an innocent person
```

---

# 🎯 Medical Test Example

Suppose a test checks for a disease.

### Null Hypothesis

```text
The patient is healthy
```

Test result says:

```text
The patient has the disease
```

But in reality:

```text
The patient is healthy
```

This is:

```text
Type 1 Error
```

Also called:

```text
False Positive
```

---

# 🚨 Type 2 Error

Now Professor Arjun explains the second error.

```text
Type 2 Error
= Failing to reject H₀ when it is actually FALSE
```

Symbol:

```text
β (beta)
```

---

# 🎯 Court Example

### Null Hypothesis

```text
The person is innocent
```

Court decision:

```text
The person is innocent
```

But reality:

```text
The person was guilty
```

This is:

```text
Type 2 Error
```

Meaning:

```text
Letting a guilty person go free
```

---

# 🎯 Medical Test Example

### Null Hypothesis

```text
The patient is healthy
```

Test result says:

```text
Healthy
```

But reality:

```text
The patient actually has the disease
```

This is:

```text
Type 2 Error
```

Also called:

```text
False Negative
```

---

# 📊 Simple Summary

| Error Type   | Meaning         | Example                  |
| ------------ | --------------- | ------------------------ |
| Type 1 Error | Reject true H₀  | Innocent person punished |
| Type 2 Error | Accept false H₀ | Guilty person released   |

---

# 🧠 Visual Idea

```text
                Reality
              True     False
Decision
Reject H₀     Type 1   Correct
Keep H₀       Correct   Type 2
```

# 🤖 Milo Connects It to Machine Learning

Milo explains something interesting.

These errors are **exactly like classification mistakes in ML**.

Example: **Spam Detection**

| Actual   | Prediction | Result       |
| -------- | ---------- | ------------ |
| Not Spam | Spam       | Type 1 Error |
| Spam     | Not Spam   | Type 2 Error |

---

# 🧠 Why α Matters

Remember:

```text
α = Probability of Type 1 Error
```

So when we choose:

```text
α = 0.05
```

We are saying:

```text
We accept a 5% chance of making a Type 1 Error.
```

# 🧪 Simple Python Simulation

We will simulate random coin tosses.

---

# Step 1 — Import Library

```python
# Import numpy for random number generation
import numpy as np
```

Explanation:

```text
numpy helps generate random numbers and simulate experiments.
```

---

# Step 2 — Simulate Coin Toss

```python
# Simulate 100 coin tosses

coin_toss = np.random.binomial(n=1, p=0.5, size=100)
```

Explanation:

```text
n = 1 → one coin toss
p = 0.5 → fair coin probability
size = 100 → number of tosses
```

---

# Step 3 — Count Heads

```python
# Count number of heads

heads = np.sum(coin_toss)

print("Number of Heads:", heads)
```

Explanation:

```text
We check how many heads occurred.
```

If we saw **extreme results**, we might wrongly reject the fair coin hypothesis.

That would be a **Type 1 error**.
