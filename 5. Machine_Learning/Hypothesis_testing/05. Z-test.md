# 🧠 Step 1 — First Understand Population vs Sample

Before understanding a Z-test, we must understand **two basic ideas**.

### Population

```text
Population = Entire group we want to study
```

Example:

```text
All students in a school
All voters in a country
All customers of a company
```

---

### Sample

```text
Sample = A small group selected from the population
```

Example:

```text
Surveying 100 students from a school of 2000 students
```

We usually study **samples**, not entire populations, because studying the whole population is expensive or impossible.

---

# 🎯 Example Scenario

Professor Arjun gives an example.

A school claims:

```text
Average exam score of students = 70
```

So our **Null Hypothesis** is:

```text
H₀ : μ = 70
```

Where:

```text
μ (mu) = population mean
```

Now we collect scores from **30 students**.

The average score turns out to be:

```text
Sample mean = 75
```

Now the question is:

```text
Is the difference between 75 and 70 real?
OR
Did it happen by random chance?
```

To answer this, we use a **Z-Test**.

---

# 🧠 Step 2 — Idea Behind Z-Test

The Z-test checks:

```text
How far the sample mean is from the population mean
in terms of standard deviation.
```

In simple words:

```text
Z-test measures how unusual our sample result is.
```

---

# 📊 The Z-Score Formula

Professor Arjun writes the formula on the board.

```text
Z = (x̄ − μ) / (σ / √n)
```

Now Milo explains each symbol.

| Symbol | Meaning                       |
| ------ | ----------------------------- |
| x̄     | Sample mean                   |
| μ      | Population mean               |
| σ      | Population standard deviation |
| n      | Sample size                   |

---

# 🧠 What This Formula Means

This formula basically measures:

```text
How many standard deviations
the sample mean is away from the population mean.
```

Example:

```text
Z = 0 → sample mean equals population mean
Z = 2 → sample mean is 2 standard deviations away
Z = 3 → very unusual result
```

Large Z values mean the result is **rare**.

---

# 🎯 Simple Intuition

Imagine the average height in a city is:

```text
170 cm
```

You measure a sample and find:

```text
Sample average = 210 cm
```

That seems **very unusual**.

A Z-test calculates exactly **how unusual that difference is**.

---

# 📊 The Normal Distribution

The Z-test works with something called a **normal distribution**.

This looks like a **bell-shaped curve**.

```
                *
             *     *
           *         *
         *             *
------*------------------*------
     -2      0        +2
```

Key idea:

```text
Most data lies near the center
Extreme values are rare
```

---

# 🧠 Important Rule

In a normal distribution:

| Z-score | Probability |
| ------- | ----------- |
| ±1      | 68% data    |
| ±2      | 95% data    |
| ±3      | 99.7% data  |

So if:

```text
|Z| > 2
```

The result is **very unusual**.

---

# 🎯 Example Calculation

Suppose:

```text
Population mean = 70
Population std deviation = 10
Sample size = 25
Sample mean = 75
```

Now calculate Z.

Step 1

```
σ / √n = 10 / √25
```

```
= 10 / 5
```

```
= 2
```

Step 2

```
Z = (75 − 70) / 2
```

```
Z = 5 / 2
```

```
Z = 2.5
```

---

# 🧠 Interpretation

```
Z = 2.5
```

This means the sample mean is **2.5 standard deviations away**.

That is **very rare**.

So we may:

```text
Reject the Null Hypothesis
```

---

# 🤖 Milo Explains in Simple Words

```text
Z-test checks whether the difference between
sample mean and population mean
is large enough to be considered real.
```

# 🧪 Python Example (Z-Test)

Now we will perform a Z-test using Python.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical calculations
import numpy as np

# Import the z-test function
from statsmodels.stats.weightstats import ztest
```

Explanation:

```
numpy → used for numerical operations
ztest → performs the Z-test
```

---

# Step 2 — Create Sample Data

```python
# Example exam scores from 30 students

scores = np.array([
72, 75, 78, 70, 74, 76, 77, 73, 71, 79,
80, 74, 73, 76, 78, 72, 75, 77, 79, 81,
70, 74, 76, 78, 72, 73, 75, 77, 80, 82
])
```

Explanation:

```
These are exam scores from a sample of students.
```

---

# Step 3 — Perform Z-Test

```python
# Perform Z-test comparing sample mean with population mean = 70

z_statistic, p_value = ztest(scores, value=70)
```

Explanation:

```
value = 70 → population mean we are testing against
```

The function returns:

```
z_statistic → how far the sample mean is from population mean
p_value → probability of observing such difference randomly
```

---

# Step 4 — Print Results

```python
# Display results

print("Z-statistic:", z_statistic)
print("P-value:", p_value)
```

---

# Step 5 — Decision

```python
# Define significance level
alpha = 0.05

# Decision rule
if p_value < alpha:
    print("Reject the Null Hypothesis")
else:
    print("Fail to Reject the Null Hypothesis")
```

Explanation:

```
If p-value < 0.05 → result is statistically significant
```
