# 🧠 Step 1 — What is Significance Level?

Professor Arjun writes on the board.

```text
Significance Level (α)
= The maximum probability of making a wrong rejection
  of the Null Hypothesis that we are willing to accept.
```

That sounds complicated.

So Milo explains it simply.

```text
α = How strict we want our test to be
```

---

# 🧠 Step 2 — Why Do We Need α?

Remember:

The **p-value** tells us:

```text
How surprising the data is.
```

But we need a **rule** to decide:

```text
When is the result surprising enough?
```

That rule is:

```text
Significance Level (α)
```

---

# 🎯 Standard Values of α

Most commonly used values are:

| α Value | Meaning           |
| ------- | ----------------- |
| 0.10    | 10% error allowed |
| 0.05    | 5% error allowed  |
| 0.01    | 1% error allowed  |

Most scientific studies use:

```text
α = 0.05
```

---

# 🧠 Step 3 — Decision Rule

Professor Arjun explains the most important rule in hypothesis testing.

### Rule

```text
If p-value < α
→ Reject Null Hypothesis
```

```text
If p-value ≥ α
→ Fail to Reject Null Hypothesis
```

---

# 🎯 Example

Suppose we conduct a test.

We calculate:

```text
p-value = 0.03
```

And we choose:

```text
α = 0.05
```

Now compare:

```text
0.03 < 0.05
```

So we:

```text
Reject H₀
```

---

# 🧠 Another Example

Suppose:

```text
p-value = 0.08
α = 0.05
```

Now compare:

```text
0.08 > 0.05
```

So we:

```text
Fail to Reject H₀
```

---

# 🎯 Simple Real-Life Analogy

Professor Arjun gives an example.

Imagine a **metal detector at an airport**.

The machine sometimes makes mistakes.

Airport security decides:

```text
We accept only 5% chance of false alarm.
```

That **5% tolerance** is like:

```text
α = 0.05
```

If the alarm probability is **very small**, security believes the threat is real.

---

# 🧠 Visualization

Think of α as a **line that separates normal results from surprising results**.

```
Normal Results           Surprising Results
|-----------------------|-------------------|
                        α = 0.05
```

If the p-value falls into the **surprising region**, we reject the null hypothesis.

# 🧪 Python Example

Now let's implement the **decision rule using Python**.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical operations
import numpy as np

# Import the t-test function
from scipy.stats import ttest_1samp
```

Explanation:

```
numpy → used to work with numbers
ttest_1samp → performs a one-sample t-test
```

---

# Step 2 — Create Sample Data

```python
# Exam scores of students

scores = np.array([72, 75, 78, 70, 74, 76, 77, 73, 71, 79])
```

Explanation:

```
We collected exam scores from 10 students.
```

---

# Step 3 — Perform Hypothesis Test

```python
# Perform one-sample t-test
# We compare the sample mean with 60

t_statistic, p_value = ttest_1samp(scores, 60)
```

Explanation:

```
This test checks whether the average score
is significantly different from 60.
```

---

# Step 4 — Define Significance Level

```python
# Define significance level

alpha = 0.05
```

Explanation:

```
We allow only 5% probability of error.
```

---

# Step 5 — Decision Making

```python
# Compare p-value with alpha

if p_value < alpha:
    print("Reject the Null Hypothesis")
else:
    print("Fail to Reject the Null Hypothesis")
```

Explanation:

```
If the p-value is smaller than alpha,
the result is statistically significant.
```
