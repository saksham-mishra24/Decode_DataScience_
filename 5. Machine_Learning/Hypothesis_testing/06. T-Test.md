# 🧠 Step 1 — When Do We Use a T-Test?

We use a **T-test** when:

```text
1. Population standard deviation is unknown
2. Sample size is small
```

In practice:

```text
Most real-world hypothesis tests use a T-test.
```

---

# 🎯 Example Scenario

Professor Arjun gives a simple example.

A school claims:

```text
Average student score = 70
```

So the **Null Hypothesis** is:

```text
H₀ : μ = 70
```

We collect scores from **10 students**.

The average score becomes:

```text
Sample mean = 75
```

Now we ask:

```text
Is this difference real
or just random chance?
```

To answer this, we use a **T-test**.

---

# 🧠 Step 2 — T-Test Formula

Professor Arjun writes the formula.

```text
t = (x̄ − μ) / (s / √n)
```

Now Milo explains each symbol.

| Symbol | Meaning                   |
| ------ | ------------------------- |
| x̄     | Sample mean               |
| μ      | Population mean           |
| s      | Sample standard deviation |
| n      | Sample size               |

---

# 🧠 Difference Between Z and T Test

| Z-Test                   | T-Test                 |
| ------------------------ | ---------------------- |
| Population std known     | Population std unknown |
| Usually large sample     | Usually small sample   |
| Uses normal distribution | Uses t-distribution    |

---

# 📊 What is a T-Distribution?

The **t-distribution** looks similar to the normal distribution but has **fatter tails**.

Why?

Because when we have **small samples**, uncertainty is larger.

Simple visualization:

Normal Distribution

```
        *
      *   *
    *       *
---*---------*---
```

T-Distribution

```
        *
      *   *
    *       *
---*---------*---
(wider tails)
```

Meaning:

```text
Extreme values are more likely with small samples.
```

---

# 🧠 Degrees of Freedom

Another new idea appears in the T-test.

```text
Degrees of Freedom (df)
```

Formula:

```text
df = n − 1
```

Example:

If sample size:

```text
n = 10
```

Then:

```text
df = 9
```

Degrees of freedom control **the shape of the t-distribution**.

---

# 🎯 Example Calculation

Suppose:

```
Sample mean = 75
Population mean = 70
Sample std deviation = 8
Sample size = 16
```

Step 1

```
√n = √16 = 4
```

Step 2

```
s / √n = 8 / 4 = 2
```

Step 3

```
t = (75 − 70) / 2
```

```
t = 5 / 2
```

```
t = 2.5
```

So:

```
t = 2.5
```

Then we use the **t-distribution table** to find the **p-value**.

# 📘 Types of T-Tests

Professor Arjun writes on the board.

There are **three types of T-tests**.

```
1. One-Sample T-Test
2. Independent T-Test
3. Paired T-Test
```

We will understand them one by one.

---

# 🧠 1️⃣ One-Sample T-Test

Used when:

```text
Comparing sample mean with population mean
```

Example:

```
School claims average score = 70
```

We check if our sample supports that claim.

---

# 🧠 2️⃣ Independent T-Test

Used when comparing **two different groups**.

Example:

```
Average marks of boys vs girls
```

or

```
Marks of students taught by Method A vs Method B
```

---

# 🧠 3️⃣ Paired T-Test

Used when **same group is measured twice**.

Example:

```
Marks before training
Marks after training
```

Or:

```
Weight before diet
Weight after diet
```

---

# 🧪 Python Example — One-Sample T-Test

Now let's implement this in Python.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical operations
import numpy as np

# Import t-test function
from scipy.stats import ttest_1samp
```

Explanation:

```
numpy → used for numerical calculations
ttest_1samp → performs a one-sample t-test
```

---

# Step 2 — Create Sample Data

```python
# Example exam scores from 10 students

scores = np.array([72, 75, 78, 70, 74, 76, 77, 73, 71, 79])
```

Explanation:

```
These are exam scores collected from students.
```

---

# Step 3 — Perform T-Test

```python
# Perform one-sample t-test
# Compare sample mean with population mean = 70

t_statistic, p_value = ttest_1samp(scores, 70)
```

Explanation:

```
70 is the claimed population mean
```

The function returns:

```
t_statistic → strength of difference
p_value → probability that difference occurred randomly
```

---

# Step 4 — Print Results

```python
# Display results

print("T-statistic:", t_statistic)
print("P-value:", p_value)
```

---

# Step 5 — Decision Rule

```python
# Define significance level
alpha = 0.05

# Check hypothesis

if p_value < alpha:
    print("Reject the Null Hypothesis")
else:
    print("Fail to Reject the Null Hypothesis")
```

Explanation:

```
If p-value < 0.05 → statistically significant difference
```
