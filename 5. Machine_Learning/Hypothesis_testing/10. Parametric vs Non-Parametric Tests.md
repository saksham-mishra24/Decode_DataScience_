# 🧠 Step 1 — What is a Parameter?

Professor Arjun gives an example.

Suppose we measure the **height of all students in a school**.

If we calculate the **average height**, that number is called a **parameter**.

Example:

```
Average height of students = 165 cm
```

This number **describes the entire population**.

That is why it is called a **parameter**.

---

# 🧠 Step 2 — What is a Parametric Test?

Professor Arjun explains.

```
Parametric Test = A statistical test that assumes
the data follows a specific distribution
(usually a normal distribution).
```

Riya asks:

> **Riya:** Sir, what does “distribution” mean?

Professor Arjun explains.

A **distribution** describes **how data is spread**.

The most common one is the **Normal Distribution**.

```
Normal Distribution → Bell-shaped curve
```

Characteristics:

```
Mean = Median = Mode
Symmetrical shape
Most values near the center
```

---

# 📊 Example of Parametric Test Situation

Suppose we measure **exam scores of students**.

| Student | Score |
| ------- | ----- |
| A       | 70    |
| B       | 75    |
| C       | 80    |
| D       | 78    |
| E       | 82    |

These scores are **nicely spread around the average**.

So they often follow a **normal distribution**.

In such cases we can use **parametric tests**.

---

# 📘 Examples of Parametric Tests

Common parametric tests include:

### 1️⃣ Z-Test

Used when:

```
Sample size is large
Population variance known
```

---

### 2️⃣ T-Test

Used when:

```
Sample size is small
Population variance unknown
```

---

### 3️⃣ ANOVA

Used when:

```
Comparing means of 3 or more groups
```

---

# 🤖 Milo Summarizes

```
Parametric tests assume the data follows
a specific distribution (usually normal).
```

---

# 🧠 Step 3 — What is a Non-Parametric Test?

Now Professor Arjun explains the second concept.

```
Non-Parametric Test =
A statistical test that does NOT assume
any specific data distribution.
```

Riya asks:

> **Riya:** Why would we need that?

Professor Arjun gives an example.

Sometimes data looks **messy and irregular**.

Example dataset:

| Person | Income   |
| ------ | -------- |
| A      | 20,000   |
| B      | 22,000   |
| C      | 23,000   |
| D      | 25,000   |
| E      | 2,00,000 |

Here one value is extremely large.

This causes **skewed data**.

Such data **does not follow a normal distribution**.

So parametric tests **may not work well**.

Instead we use **non-parametric tests**.

---

# 📘 Examples of Non-Parametric Tests

Common ones include:

### 1️⃣ Mann-Whitney U Test

Used instead of **independent t-test**.

---

### 2️⃣ Wilcoxon Signed-Rank Test

Used instead of **paired t-test**.

---

### 3️⃣ Kruskal-Wallis Test

Used instead of **ANOVA**.

---

### 4️⃣ Chi-Square Test

Used for **categorical data**.

Example:

```
Gender vs Product Purchase
```

---

# 🧠 Step 4 — Why Non-Parametric Tests Exist

They are useful when:

```
Data is not normally distributed
Sample size is very small
Data contains outliers
Data is categorical
```

Example:

```
Customer satisfaction ratings
```

Ratings:

```
Very Bad
Bad
Neutral
Good
Excellent
```

These are **not numerical values**, so parametric tests cannot be used.

---

# 📊 Simple Comparison Table

| Feature                 | Parametric Test                   | Non-Parametric Test          |
| ----------------------- | --------------------------------- | ---------------------------- |
| Distribution assumption | Yes                               | No                           |
| Data type               | Numerical                         | Numerical or categorical     |
| Accuracy                | Higher (if assumptions satisfied) | Lower but safer              |
| Example                 | T-test, ANOVA                     | Mann-Whitney, Kruskal-Wallis |

---

# 🧠 Real Life Example

Suppose a company tests **two teaching methods**.

Method A scores:

```
70, 75, 80, 78
```

Method B scores:

```
72, 74, 77, 79
```

Data looks **normal**.

So we use:

```
T-test (parametric)
```

---

Now suppose ratings are:

```
Bad
Good
Excellent
Average
Good
```

These are **categories**, not numbers.

So we use:

```
Chi-Square test (non-parametric)
```

---

# 🧪 Python Example

Let's see a simple example.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical operations
import numpy as np

# Import t-test (parametric test)
from scipy.stats import ttest_ind

# Import Mann-Whitney test (non-parametric test)
from scipy.stats import mannwhitneyu
```

Explanation:

```
ttest_ind → parametric test
mannwhitneyu → non-parametric test
```

---

# Step 2 — Create Two Sample Groups

```python
# Scores from teaching method A
group_A = [70, 75, 80, 78, 82]

# Scores from teaching method B
group_B = [72, 74, 77, 79, 81]
```

These represent **exam scores from two teaching methods**.

---

# Step 3 — Parametric Test (T-Test)

```python
# Perform independent t-test
t_stat, p_value = ttest_ind(group_A, group_B)

# Print results
print("T-statistic:", t_stat)
print("P-value:", p_value)
```

This checks whether the **means of two groups are different**.

---

# Step 4 — Non-Parametric Test

```python
# Perform Mann-Whitney U test
stat, p_value = mannwhitneyu(group_A, group_B)

# Print results
print("Statistic:", stat)
print("P-value:", p_value)
```

This compares **rankings instead of means**.

---
