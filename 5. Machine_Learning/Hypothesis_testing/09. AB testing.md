# 🧠 Step 1 — Basic Idea of A/B Testing

Suppose a company has a **website button**.

Version A:

```text
"Buy Now"
```

Version B:

```text
"Get Started"
```

The company wants to know:

```text
Which button makes more people click?
```

So they test both versions.

---

# 🎯 How A/B Testing Works

Visitors are randomly divided into two groups.

| Group   | Version   |
| ------- | --------- |
| Group 1 | Version A |
| Group 2 | Version B |

Then the company measures:

```text
Click Rate
```

Example results:

| Version | Visitors | Clicks |
| ------- | -------- | ------ |
| A       | 1000     | 120    |
| B       | 1000     | 170    |

Now we ask:

```text
Is version B truly better?
Or did this happen by chance?
```

To answer this, we use **hypothesis testing**.

---

# 🧠 Step 2 — Hypotheses in A/B Testing

### Null Hypothesis (H₀)

```text
Both versions perform the same.
```

Example:

```text
Click rate A = Click rate B
```

---

### Alternative Hypothesis (H₁)

```text
Versions perform differently.
```

Example:

```text
Click rate A ≠ Click rate B
```

---

# 🧠 Step 3 — Metrics Used in A/B Testing

Companies measure something called **conversion rate**.

Conversion Rate Formula:

```text
Conversion Rate = (Number of Conversions / Total Visitors)
```

Example:

Version A:

```text
120 / 1000 = 0.12
```

Version B:

```text
170 / 1000 = 0.17
```

So B looks better.

But we must check if the difference is **statistically significant**.

---

# 📊 Visual Idea

Think of it like this:

```text
Version A → 12% click rate
Version B → 17% click rate
```

Question:

```text
Is the 5% improvement real?
```

Hypothesis testing answers this.

---

# 🧠 Step 4 — Randomization (Very Important)

Professor Arjun explains something crucial.

Users must be **randomly assigned**.

Example:

```text
User 1 → Version A
User 2 → Version B
User 3 → Version A
User 4 → Version B
```

Why?

Because randomization removes **bias**.

If we did not randomize, results might be misleading.

# 🧠 Step 5 — Statistical Test Used

Usually A/B testing uses:

```text
Two-sample T-test
```

or

```text
Z-test for proportions
```

These tests determine if the difference is **significant**.

# 🧪 Python Example — Simple A/B Test

Let's simulate A/B testing.

---

# Step 1 — Import Libraries

```python
# Import numpy for calculations
import numpy as np

# Import statistical test
from statsmodels.stats.proportion import proportions_ztest
```

Explanation:

```text
numpy → numerical calculations
proportions_ztest → compares two conversion rates
```

---

# Step 2 — Define Data

```python
# Number of clicks (success)
clicks = np.array([120, 170])

# Number of visitors
visitors = np.array([1000, 1000])
```

Explanation:

```text
Version A → 120 clicks out of 1000 visitors
Version B → 170 clicks out of 1000 visitors
```

---

# Step 3 — Perform Z-Test

```python
# Perform A/B test

z_stat, p_value = proportions_ztest(clicks, visitors)
```

This calculates:

```text
z_stat → difference strength
p_value → probability difference happened randomly
```

---

# Step 4 — Print Results

```python
print("Z-statistic:", z_stat)
print("P-value:", p_value)
```

---

# Step 5 — Decision Rule

```python
alpha = 0.05

if p_value < alpha:
    print("Reject Null Hypothesis → Version B is better")
else:
    print("No significant difference")
```

Explanation:

```text
If p-value < 0.05
→ improvement is statistically significant
```
