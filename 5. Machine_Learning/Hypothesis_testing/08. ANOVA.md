# 🧠 Step 1 — Why Do We Need ANOVA?

Let’s imagine a simple scenario.

A school wants to test **three teaching methods**.

```text
Method A
Method B
Method C
```

They want to know:

```text
Which teaching method gives better student marks?
```

We collect exam scores.

| Method A | Method B | Method C |
| -------- | -------- | -------- |
| 78       | 85       | 90       |
| 80       | 88       | 92       |
| 76       | 84       | 89       |
| 82       | 87       | 91       |

Now we ask:

```text
Are these differences real?
Or just random variation?
```

To answer this, we use **ANOVA**.

---

# 🧠 Step 2 — Hypotheses in ANOVA

### Null Hypothesis (H₀)

```text
All group means are equal
```

Example:

```text
Mean(A) = Mean(B) = Mean(C)
```

---

### Alternative Hypothesis (H₁)

```text
At least one group mean is different
```

Important:

ANOVA **does NOT tell which group is different**.

It only tells:

```text
At least one group differs
```

---

# 🧠 Step 3 — Basic Idea Behind ANOVA

ANOVA compares **two types of variation**.

Professor Arjun writes:

```text
1. Variation Between Groups
2. Variation Within Groups
```

---

## 1️⃣ Between Group Variation

This measures how different the **group averages** are.

Example:

```text
Average of Method A
Average of Method B
Average of Method C
```

If these averages are **very different**, the teaching method likely matters.

---

## 2️⃣ Within Group Variation

This measures variation **inside each group**.

Example:

Even within Method A, students have different marks.

```text
78
80
76
82
```

This variation happens **naturally**.

---

# 🎯 Key Idea of ANOVA

ANOVA checks:

```text
Is between-group variation
much larger than within-group variation?
```

If yes → groups are likely **different**.

---

# 📊 ANOVA Test Statistic

ANOVA uses something called the **F-statistic**.

Formula idea:

```text
F = Between Group Variance
    ----------------------
    Within Group Variance
```

---

### Interpretation

| F Value | Meaning              |
| ------- | -------------------- |
| Small F | Groups are similar   |
| Large F | Groups are different |

So:

```text
Large F → Reject H₀
```

---

# 🧠 Simple Analogy

Imagine three cricket teams practicing.

We measure **average batting score**.

If the averages are:

```text
Team A = 50
Team B = 52
Team C = 51
```

These are very similar.

So the training methods probably **do not matter much**.

---

But if the averages are:

```text
Team A = 50
Team B = 80
Team C = 90
```

Now the difference is **huge**.

So training method likely **affects performance**.

ANOVA detects this difference.

# 🧪 Python Example — ANOVA

Now let's perform ANOVA using Python.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical calculations
import numpy as np

# Import ANOVA test function
from scipy.stats import f_oneway
```

Explanation:

```
numpy → for creating datasets
f_oneway → performs one-way ANOVA
```

---

# Step 2 — Create Sample Data

```python
# Exam scores for students taught by three methods

method_A = np.array([78, 80, 76, 82])
method_B = np.array([85, 88, 84, 87])
method_C = np.array([90, 92, 89, 91])
```

Explanation:

```
Each array represents scores from one teaching method.
```

---

# Step 3 — Perform ANOVA

```python
# Perform one-way ANOVA test

F_statistic, p_value = f_oneway(method_A, method_B, method_C)
```

Explanation:

```
f_oneway compares the means of multiple groups.
```

It returns:

```
F_statistic → strength of difference
p_value → probability result happened randomly
```

---

# Step 4 — Print Results

```python
print("F-statistic:", F_statistic)
print("P-value:", p_value)
```

---

# Step 5 — Decision Rule

```python
alpha = 0.05

if p_value < alpha:
    print("Reject Null Hypothesis")
else:
    print("Fail to Reject Null Hypothesis")
```

Explanation:

```
If p-value < 0.05 → at least one group mean is different
```
