---

# 🧠 Step 1 — Understanding the Idea

Remember the **Null Hypothesis (H₀)**.

Example:

```text
H₀: The coin is fair.
```

This means:

```text
Probability of Heads = 50%
Probability of Tails = 50%
```

Now we perform an experiment.

We toss the coin **10 times**.

Result:

```text
Heads = 9
Tails = 1
```

Now we ask:

```text
If the coin were truly fair,
how likely is this result?
```

This probability is the **p-value**.

---

# 🧠 Step 2 — Simple Meaning of P-Value

Professor Arjun writes on the board:

```text
P-value = Probability of observing our result
          (or something more extreme)
          assuming the Null Hypothesis is true
```

But that sounds complicated.

So Milo explains it simply:

```text
P-value = How surprising the data is
```

---

# 🎯 Example — Exam Scores

Suppose a school claims:

```text
Average score = 60
```

So the **Null Hypothesis** is:

```text
H₀ : Average score = 60
```

Now we collect data from students.

The average score turns out to be:

```text
Average = 75
```

Now we ask:

```text
If the real average were 60,
how likely would we see an average of 75?
```

If that probability is **very small**, the claim is probably wrong.

That probability is the **p-value**.

---

# 🧠 Step 3 — Interpreting P-Value

Professor Arjun explains the rule.

### If P-Value is Small

```text
p-value < 0.05
```

Meaning:

```text
The result is very unlikely under the Null Hypothesis.
```

So we:

```text
Reject H₀
```

---

### If P-Value is Large

```text
p-value ≥ 0.05
```

Meaning:

```text
The result could easily happen by chance.
```

So we:

```text
Fail to reject H₀
```

---

# 🎯 Why 0.05?

Riya asks:

> **Riya:** Sir, why do we use **0.05**?

Professor Arjun replies:

```text
0.05 = 5% probability
```

Meaning:

```text
We accept only a 5% chance
that the result happened randomly.
```

If the probability is **less than 5%**, we say:

```text
This is statistically significant.
```

---

# 🧠 Simple Analogy

Imagine a bag of marbles.

Very unlikely.

That likelihood is the **p-value**.

# 🧪 Python Example (Simple Demonstration)

Now let's compute a **p-value using Python**.

We will perform a **one-sample t-test**.

---

# Step 1 — Import Libraries

```python
# Import numpy for numerical calculations
import numpy as np

# Import t-test function from scipy
from scipy.stats import ttest_1samp
```

Explanation:

```
numpy → used for working with numbers and arrays
ttest_1samp → performs a one-sample t-test
```

---

# Step 2 — Create Sample Data

```python
# Example: exam scores of 10 students

scores = np.array([72, 75, 78, 70, 74, 76, 77, 73, 71, 79])
```

Explanation:

```
We collected exam scores from 10 students.
```

---

# Step 3 — Define Hypothesis

School claim:

```text
Average score = 60
```

So we test against:

```python
# Perform one-sample t-test

t_statistic, p_value = ttest_1samp(scores, 60)
```

Explanation:

```
ttest_1samp compares the sample mean
with a given population mean (60)
```

The function returns:

```
t_statistic → strength of difference
p_value → probability of seeing this difference randomly
```

---

# Step 4 — Print Results

```python
# Print results

print("T-statistic:", t_statistic)
print("P-value:", p_value)
```

---

# Step 5 — Decision Rule

```python
# Check if p-value is less than 0.05

if p_value < 0.05:
    print("Reject the Null Hypothesis")
else:
    print("Fail to Reject the Null Hypothesis")
```

Explanation:

```
If p-value < 0.05
→ the difference is statistically significant
```
