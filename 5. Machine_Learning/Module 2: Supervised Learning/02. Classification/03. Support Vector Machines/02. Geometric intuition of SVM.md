# ✏️ Step 2 — What Is the Hyperplane?

In **2D**, the boundary is a **line**.

Example:

```text
ax + by + c = 0
```

Graphically:

```
Pass points     |     Fail points
      ●         |        ●
      ●         |        ●
--------------- LINE ----------------
```

In **3D**, the boundary becomes a **plane**.

In **higher dimensions**, we call it a:

# Hyperplane

So:

```text
2D → line
3D → plane
nD → hyperplane
```

# 📏 Step 4 — The Idea of Margin

SVM introduces a powerful idea:

Instead of choosing **any line**, choose the one with the **maximum margin**.

Margin = **distance from the boundary to the nearest points**

Imagine two groups of people standing apart.

```
Group A        YOU        Group B
```

The safest place to stand is **right in the middle**.

That middle line creates the **largest gap**.

# 🤖 Step 5 — The Important Points (Support Vectors)

Now Milo notices something interesting.

Most points **do not matter**.

Only the **closest points** affect the boundary.

These points are called:

# Support Vectors

```
Class A        Class B
   ●              ●
   ●              ●
      \        /
       \______/   ← boundary controlled here
```

If we remove other points, the boundary stays the same.

But if we move **support vectors**, the boundary moves.

---

# 🧠 Step 6 — Why Maximum Margin Works

Professor gives a real-life example.

Imagine drawing a road between two villages.

Bad road:

```
Village A | Road | Village B
```

Very narrow gap.

A small shift causes collision.

Better road:

```
Village A      Road      Village B
```

Large gap.

More safety.

Same idea in ML:

```
Small margin → sensitive to noise
Large margin → robust model
```

# 📐 Mathematical Idea (Simple Version)

The distance of a point from the hyperplane is:

```
Distance = |w·x + b| / ||w||
```

Where:

```
w = weights
b = bias
```

SVM tries to **maximize this distance** for the closest points.

So mathematically it solves:

```
Maximize margin
```

Which becomes:

```
Minimize ||w||²
```

Subject to correct classification.
