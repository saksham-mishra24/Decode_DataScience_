# 🤔 Scene 2 — Milo Gets an Idea

Milo says:

> What if we **change the space**?

Right now the data lives in:

```text
2D space
(x , y)
```

Milo creates a **new feature**:

```text
z = x² + y²
```

This adds a **third dimension**.

Now every point becomes:

```text
(x , y , z)
```

So the data moves from:

```text
2D → 3D
```

# 🎯 Step 4 — Bring the Boundary Back

The model finds a **plane in 3D**.

But when we **project it back to 2D**, it becomes a **curve**.

So instead of a straight line we get:

```text
Circle boundary
```

Example:

```text
Inside circle → Red
Outside circle → Blue
```

---

# 🧠 The Genius Idea

SVM does something very smart.

Instead of actually computing **3D coordinates**, it uses a **kernel function**.

Kernel functions **simulate higher dimensions without computing them directly**.

So we never actually compute:

```text
(x , y , z)
```

But the math behaves **as if we did**.

This trick is called:

# Kernel Trick

---

# ⚙️ Popular Kernels

Different kernels create different shapes.

| Kernel         | Boundary Shape      |
| -------------- | ------------------- |
| Linear         | Straight line       |
| Polynomial     | Curves              |
| RBF (Gaussian) | Flexible shapes     |
| Sigmoid        | Neural-network-like |

The most famous one is:

```text
RBF Kernel
```

Because it creates **very flexible boundaries**.

---

# 🧠 Geometric Intuition of RBF

RBF creates **bubbles around points**.

Nearby points influence predictions.
