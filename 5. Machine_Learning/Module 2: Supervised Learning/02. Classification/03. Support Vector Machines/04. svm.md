# ✏️ Step 1 — Draw a Boundary (Hyperplane)

SVM tries to separate the classes using a **line**.

In 2D:

```
ax + by + c = 0
```

Graphically:

```
Red points | Blue points
------------LINE-----------
```

In higher dimensions this becomes a **hyperplane**.

---

# 📏 Step 2 — Find the Maximum Margin

Many lines can separate the data.

SVM chooses the **best one**.

Best means:

```
The line with the largest distance from both classes
```

This distance is called the **margin**.

The algorithm **maximizes this margin**.

Why?

Because a larger margin means the model is **more confident and stable**.

---

# 🎯 Step 3 — Identify Support Vectors

Now something surprising happens.

Only a **few points** determine the boundary.

These are the **closest points to the margin**.

They are called:

```
Support Vectors
```

Example:

```
Class A   |   Class B
   ●      |      ●
          |
----------LINE----------
```

If these points move, the boundary moves.

Other points **do not affect the model**.

---

# 🧠 Step 4 — Solve an Optimization Problem

Mathematically, SVM tries to:

```
Maximize margin
```

Which becomes:

```
Minimize ||w||²
```

Subject to correct classification.

So SVM solves an **optimization problem** to find the best boundary.

---

# 📌 Summary of How SVM Works

The algorithm follows these steps:

```
1. Plot data points in feature space
2. Find possible separating hyperplanes
3. Choose the hyperplane with maximum margin
4. Identify support vectors
5. Use them to define the final decision boundary
```

---

# 🎯 2. How Does SVM Classify New Data?

Once the boundary is found, classification becomes easy.

Suppose the hyperplane equation is:

```
w·x + b = 0
```

For a new point **x**:

### Case 1

```
w·x + b > 0
```

Prediction → **Class +1**

### Case 2

```
w·x + b < 0
```

Prediction → **Class −1**

Example:

```
Positive side → Pass
Negative side → Fail
```

So SVM simply checks **which side of the boundary the point lies on**.

# 2️⃣ Non-Linear SVM

Sometimes data looks like this:

* circular
* curved
* complex patterns

A straight line **cannot separate it**.

![Image](https://cdn.hashnode.com/res/hashnode/image/upload/v1735885699184/222d7252-7ece-4e31-97f5-577bb8577797.png)

![Image](https://miro.medium.com/1%2A_Uhpj662QpxoIa8qlPYJ9A.png)

![Image](https://mldemystified.com/posts/basics-of-ml/support-vector-machines/images/kernel-svm-example.png)

![Image](https://www.researchgate.net/publication/225415339/figure/fig1/AS%3A648614107955200%401531653062199/Decision-boundary-by-SVM-with-RBF-kernel-function.png)

So SVM uses the **Kernel Trick**.

Kernels transform the data into a **higher dimension** where separation becomes possible.

Common kernels:

```
Linear Kernel
Polynomial Kernel
RBF (Gaussian) Kernel
Sigmoid Kernel
```

The most popular one is:

```
RBF Kernel
```

# 🧠 Final Big Picture

The whole SVM idea can be remembered like this:

```
1. Find a boundary between classes
2. Make the boundary as far from points as possible
3. Use support vectors to define it
4. Use kernels for complex data
```
