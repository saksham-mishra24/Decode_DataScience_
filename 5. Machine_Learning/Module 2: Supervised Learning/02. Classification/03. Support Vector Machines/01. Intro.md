# ✏️ Scene 2 — Drawing a Boundary

A simple model draws a line like this:

```text
Apple | Orange
```

Example:

```text
Weight > 150g → Orange
Weight ≤ 150g → Apple
```

Graphically:

```
Points | Points
------ LINE ------
```

This line is called a:

# Decision Boundary

# 🧠 Scene 4 — The Smart Idea of SVM

Professor Arjun says:

> “We choose the line that leaves the **maximum space** between the two classes.”

Not just any line.

But the **safest line**.

Imagine two groups standing apart.

Instead of walking close to them, you walk **in the middle**.

```
Group A      YOU      Group B
```

This **maximum gap** is called:

# Margin

---

# 📏 What Is Margin?

Margin = **distance between the boundary and nearest points**

SVM tries to **maximize this margin**.

So the model finds:

```text
The line with the largest margin
```

Why?

Because that boundary is **more robust to new data**.

---

# 🤖 Scene 5 — The Important Points

Milo observes something interesting.

Only a few points actually **control the boundary**.

These are the **closest points to the line**.

They are called:

# Support Vectors

```
Class A      |      Class B
   ●         |         ●
             |
-------------LINE-------------
```

Those nearest points **support the boundary**.

Hence the name:

# Support Vector Machine

---

# 🧠 Big Intuition

SVM does **three things**:

1️⃣ Draws a **decision boundary (hyperplane)**
2️⃣ Finds points closest to boundary (**support vectors**)
3️⃣ Chooses boundary with **maximum margin**

---

# 🎯 Why Maximum Margin Is Good

If new data arrives slightly noisy:

Small margin → model breaks easily
Large margin → model stays stable

Example:

```
Small margin → mistake likely
Large margin → safer prediction
```

---

# 📌 Important Terms (First SVM Vocabulary)

| Term            | Meaning                |
| --------------- | ---------------------- |
| Hyperplane      | Decision boundary      |
| Margin          | Distance from boundary |
| Support Vectors | Closest points         |
| Maximum Margin  | SVM goal               |
