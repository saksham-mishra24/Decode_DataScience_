# 🧠 The Sigmoid Formula

The sigmoid function looks like this:

```
σ(z) = 1 / (1 + e^(-z))
```

Where:

| Symbol | Meaning                                  |
| ------ | ---------------------------------------- |
| z      | Any number from the linear equation      |
| e      | A special mathematical constant (~2.718) |
| σ(z)   | Output probability                       |

Important thing to notice:

The structure is always:

```
1 / something
```

That structure is the **key to keeping values between 0 and 1**.

---

# 🌟 First Important Idea: The Numerator Is Always 1

Look at the formula:

```
σ(z) = 1 / (1 + e^(-z))
```

The top of the fraction is **1**.

This means the result **can never exceed 1**.

Example:

```
1 / 2  = 0.5
1 / 5  = 0.2
1 / 100 = 0.01
```

Fractions with numerator **1** always produce numbers **≤ 1**.

So sigmoid **can never produce values bigger than 1**.

Milo nods.

> 🤖 “Okay… that explains why it can't go above 1.”

---

# 🌟 Second Important Idea: The Denominator Is Always Positive

Look at the bottom:

```
1 + e^(-z)
```

Two important things happen here.

### 1️⃣ The exponential term is always positive

No matter what z is:

```
e^(-z) > 0
```

Examples:

| z  | e^(-z) |
| -- | ------ |
| 2  | 0.135  |
| 0  | 1      |
| -2 | 7.39   |

Notice something important:

```
e^x is NEVER negative
```

It is **always positive**.

---

### 2️⃣ Adding 1 keeps denominator greater than 1

Since:

```
e^(-z) > 0
```

Then:

```
1 + e^(-z) > 1
```

So the denominator is **always bigger than 1**.

---

# 🎯 Putting These Two Ideas Together

Now combine both facts.

Top:

```
1
```

Bottom:

```
something bigger than 1
```

So the result must be:

```
0 < σ(z) < 1
```

Meaning the output is **always between 0 and 1**.

That’s the mathematical trick.

# 📈 Why the Curve Becomes S-Shaped

Now notice what happens as **z changes**.

### When z is very negative

```
z → -∞
```

Then

```
e^(-z) becomes huge
```

Example:

```
e^10 ≈ 22026
```

So:

```
σ(z) ≈ 1 / very big number ≈ 0
```

Left side approaches **0**.

---

### When z is very positive

```
z → +∞
```

Then

```
e^(-z) → 0
```

So:

```
1 + e^(-z) ≈ 1
```

Then:

```
σ(z) ≈ 1 / 1 = 1
```

Right side approaches **1**.

---

### When z = 0

We already saw:

```
σ(0) = 0.5
```

This is the **middle of the curve**.

---

# 🧠 Intuition: Why Exponential Makes the Curve Smooth

The exponential function grows **very fast**.

Example:

| x  | e^x   |
| -- | ----- |
| 1  | 2.7   |
| 2  | 7.4   |
| 3  | 20    |
| 5  | 148   |
| 10 | 22026 |

Because of this:

* negative z values push probability quickly toward **0**
* positive z values push probability quickly toward **1**

But near **z = 0**, changes are gradual.

That creates the **S shape**.
