# 🧠 What is Overfitting?

Professor Arjun wrote a simple sentence on the board:

> **Overfitting = When the model memorizes the training data instead of learning the pattern.**

Think of it like this.

Instead of learning **rules**, the model starts **memorizing examples**.

# 🎓 Student Analogy

Imagine two students preparing for an exam.

### Student 1

Understands the concepts.

```
Learns patterns
Understands logic
Can solve new problems
```

### Student 2

Memorizes the entire book.

```
Remembers exact answers
But only for old questions
```

Now the exam changes slightly.

Who performs better?

Student 1.

Student 2 fails.

That is exactly what happens in **overfitting**.

---

# 🌳 How Decision Trees Overfit

Decision Trees are **very flexible**.

They can keep splitting data forever.

Example dataset:

| Study Hours | Result |
| ----------- | ------ |
| 5           | Pass   |
| 6           | Pass   |
| 7           | Pass   |
| 1           | Fail   |
| 2           | Fail   |

A reasonable tree might be:

```
Study Hours > 3 ?
    YES → Pass
    NO  → Fail
```

Nice and simple.

---

But Milo keeps splitting.

```
Study Hours > 3 ?
      ↓
Study Hours > 5 ?
      ↓
Study Hours > 6 ?
      ↓
Study Hours = 6.5 ?
```

Soon every **single data point becomes its own leaf**.

The tree becomes huge.

# 🤖 Milo’s Mistake

Milo says proudly:

Professor Arjun shakes his head.

> 👨‍🏫 “That’s not always good.”

Why?

Because the model may have learned:

```
Noise

Accidental patterns
```

---

# 📉 Training vs Testing Error

This is the biggest clue.

| Model Type       | Training Error | Test Error |
| ---------------- | -------------- | ---------- |
| Good model       | Low            | Low        |
| Overfitted model | Very low       | High       |

An overfitted model becomes **too specialized**.

It cannot generalize.

---

# 🍃 Why Trees Are Prone to Overfitting

Decision Trees naturally tend to grow too much because:

```
They keep splitting
Until nodes become pure
```

But pure nodes often mean:

```
Very tiny groups
Memorized data
```

Which leads to **overfitting**.

---

# 🧠 Signs of Overfitting

Riya summarized the signs.

A tree may be overfitting if:

```
Tree depth is very large
Many tiny leaf nodes
Training accuracy = 100%
Test accuracy drops
```

That means the tree **memorized** instead of learning.

---

# ✂ The Solution: Pruning

Professor Arjun finally reveals the solution.

```
Tree Pruning
```

Pruning means:

```
Cutting unnecessary branches
```

Just like gardeners cut extra branches from trees.

The idea:

```
Remove splits that do not improve prediction
```

This keeps the tree **simple and generalizable**.

---

# 🌳 Before vs After Pruning

```
Before Pruning

        Root
       /   \
     Node  Node
     /  \    \
   Node Node  Node
   /  \
 Leaf Leaf
```

Huge tree.

---

```
After Pruning

     Root
    /    \
  Pass   Fail
```

Simple.

Cleaner.

Better.

---

# 🎯 Goal of a Good Decision Tree

A good tree should balance two things:

```
Accuracy
Simplicity
```

Too simple → Underfitting
Too complex → Overfitting

The sweet spot is **in the middle**.
