# 🌳 What is a Decision Tree?

Professor Arjun wrote:

> **Decision Tree = A model that makes predictions by asking a sequence of questions.**

Just like humans do.

Example:

Imagine deciding:

> “Should I go outside today?”

Your brain might think like this:

```
Is it raining?
     ↓
If YES → Stay home
If NO → Go outside
```

That simple **question chain** is exactly how a **Decision Tree works**.

---

# 🧠 How Humans Make Decisions

Professor Arjun asked the class:

> “How do you decide whether to watch a movie tonight?”

Riya answered:

```
Do I have free time?
    ↓
Do I feel tired?
    ↓
Is the movie interesting?
```

Each question splits the possibilities.

And slowly we reach a decision.

A Decision Tree works **exactly the same way**.

A Decision Tree has three main parts:

| Part           | Meaning          |
| -------------- | ---------------- |
| **Root Node**  | First question   |
| **Branches**   | Possible answers |
| **Leaf Nodes** | Final prediction |

Think of it like:

```
Start → Ask Question → Follow Path → Final Answer
```

# 🎭 Example: Predict Pass or Fail

Professor Arjun showed Milo a dataset.

| Study Hours | Attendance | Result |
| ----------- | ---------- | ------ |
| 5           | High       | Pass   |
| 2           | Low        | Fail   |
| 6           | High       | Pass   |
| 1           | Low        | Fail   |

Now Milo must predict:

> “Will a student **pass or fail**?”

Instead of a formula like Logistic Regression…

Milo builds a **question tree**.

```
Is Study Hours > 3?
      ↓
   YES      NO
   ↓        ↓
  Pass     Fail
```

Simple.

Clear.

Human-like.

# 🧩 Another Example: Spam Detection

A Decision Tree might ask:

```
Does the email contain "FREE"?
       ↓
     YES        NO
     ↓          ↓
Spam?      Contains link?
               ↓
            YES    NO
            ↓      ↓
           Spam   Not Spam
```

Notice how the model **keeps splitting the data**.

---

# 📦 Key Idea Behind Decision Trees

Professor Arjun explained the magic idea.

```
Start with all data
      ↓
Ask best question
      ↓
Split the data
      ↓
Repeat
      ↓
Until predictions become clear
```

Like cutting a cake into pieces until each piece contains **only one flavor**.
