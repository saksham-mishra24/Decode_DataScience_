# 🧠 What Is the Model’s Job?

The model must draw **boundaries** that separate:

```
Pass students
Fail students
```

Different algorithms draw **different shapes**.

Example:

| Model               | Boundary           |
| ------------------- | ------------------ |
| Logistic Regression | Straight line      |
| SVM                 | Straight or curved |
| Decision Tree       | Rectangles         |

Decision Trees love **rectangles**.

# 🎯 Why Trees Overfit (Geometric Reason)

If the tree grows too much:

It creates **very tiny rectangles**.

Example:

```
One rectangle → 1 training point
```

The model memorizes the data.

So when a **new point appears**, the prediction becomes unreliable.

This is why we introduced **hyperparameters** earlier.

They **limit how many rectangles can be created**.

---

# 📌 Important Rule to Remember

Decision Trees split using **one feature at a time**.

So boundaries are always:

```
Vertical lines
Horizontal lines
```

Never diagonal.

That’s why we get **rectangular regions**.

---

# 🧠 Super Important Mental Picture

Imagine the feature space like **land**.

Decision Tree builds **fences**.

```
Fence 1 → vertical
Fence 2 → horizontal
Fence 3 → vertical
```

Eventually the land becomes **rectangular plots**.

Each plot has a **class label**.
