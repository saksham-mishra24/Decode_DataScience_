# 🧠 What is Entropy?

Professor Arjun wrote a simple sentence on the board:

> **Entropy = How messy or mixed the data is.**

Think of entropy as **disorder**.

Low disorder → easy prediction
High disorder → confusing prediction


Entropy becomes **maximum**.

# 🧮 The Entropy Formula

Now Professor Arjun finally reveals the formula.

But don’t panic — it’s actually simple.

```
Entropy = − Σ ( p × log₂ p )
```

Where:

```
p = probability of a class
```

For two classes:

```
Entropy = −(p1 log₂ p1 + p2 log₂ p2)
```

Example:

```
Pass = 0.5
Fail = 0.5
```

Entropy becomes **maximum (1)**.

# 🌳 How Decision Trees Use Entropy

Now Milo understands something important.

Before splitting, the dataset may look like this:

```
Pass = 5
Fail = 5
Entropy = High
```

If Milo finds a split like:

```
Study Hours > 3
```

The new groups might look like:

Group 1:

```
Pass = 4
Fail = 1
Entropy = Low
```

Group 2:

```
Pass = 1
Fail = 4
Entropy = Low
```

This split **reduced the disorder**.

So it's a **good split**.

---

# 🎯 Goal of a Decision Tree

Decision Trees keep doing this:

```
Find split
Reduce entropy
Split again
Reduce entropy
```

Until the leaves become **pure**.

Example leaf node:

```
Pass = 10
Fail = 0
```

Perfect prediction.
