# 🧠 What is Information Gain?

Professor Arjun explained it simply:

> **Information Gain = How much disorder (entropy) decreases after a split.**

Think of it like this:

```
Messy Data
    ↓
Ask Question
    ↓
Less Messy Data
```

The question that **reduces the mess the most** is the best split.

# 🧮 The Information Gain Formula

Now the math version.

Professor Arjun writes:

```
Information Gain = Entropy(parent) − Weighted Entropy(children)
```

Translated into human language:

```
Information Gain =
Mess before split
−
Mess after split
```

If the mess decreases a lot → good split.

If the mess stays similar → bad split.

# 🤖 Milo’s Algorithm

Now Milo has a clear strategy.

For each possible question:

```
Step 1 → Calculate entropy of current data
Step 2 → Try a possible split
Step 3 → Calculate entropy of resulting groups
Step 4 → Compute Information Gain
```

Then:

```
Choose split with highest Information Gain
```

This becomes the **root node**.

Decision Trees repeat the same idea again and again.

```

       ↓

       ↓
Create two branches
       ↓
Repeat for each branch
       ↓
Stop when data becomes pure
```
