## 💻 Scene 8 — Code Time

### 🔹 Step 1: Import

```python id="rnn3_1"
import numpy as np  # numbers handle karne ke liye
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN
```

---

### 🔹 Step 2: Data

```python id="rnn3_2"
# ek sequence
X = np.array([[1, 2, 3]])

# reshape to (samples, timesteps, features)
X = X.reshape((1, 3, 1))
```

---

**Aman:**
Shape recap?

---

**Riya:**

* samples = 1
* timesteps = 3
* features = 1

---

## 🏗️ Scene 9 — Model

```python id="rnn3_3"
model = Sequential()

model.add(SimpleRNN(
    4,                      # 4 memory units → hidden state size = 4
    activation='tanh',      # values -1 se 1 ke beech rehti hain
    input_shape=(3,1),      # 3 steps, 1 value per step
    return_sequences=True   # har step ka output chahiye
))
```

---

**Aman:**
Ye 4 units kya hai?

---

**Riya:**
Matlab hidden state ka size 4 hoga:

👉 har memory = 4 numbers ka vector

---

## 📤 Scene 10 — Output
