# 🔁 Scene 7 — Step 4: Reshape


# 🏗️ Scene 8 — Step 5: Model

```python id="rnn7_5"
model = Sequential()

# LSTM layer (main brain)
model.add(LSTM(
    16,                      # 16 memory units (strong learning)
    input_shape=(X.shape[1], 1)
))

# hidden dense layer
model.add(Dense(
    8,
    activation='relu'       # non-linearity add karta hai
))

# final output
model.add(Dense(1))
```

---

### 🧠 Explanation

**Riya:**

* LSTM(16) → sequence samajhta hai
* Dense(8) → extra learning layer
* Dense(1) → final answer

---

**Aman:**
