## 🧠 Scene 13 — Deep Understanding

## 📦 Step 1: Samples

Kitni rows?

```text
4 rows
```

👉 **Samples = 4**

---

## ⏱️ Step 2: Timesteps

Ek row ki length:

```text
[1, 2, 3] → 3 values
```

👉 **Timesteps = 3**

---

## 📊 Step 3: Features

Har time step pe kya hai?

```text
t1 → 1
t2 → 2
t3 → 3
```

👉 Sirf 1 value per step
👉 **Features = 1**

---


### 🔹 Example lete hain
## 🧠 Reality kya hai?

### 👉 Har row = **ek sequence**

Matlab:

* `[1, 2, 3]` = ek sequence
* `[2, 3, 4]` = dusra sequence
* `[3, 4, 5]` = teesra

---

## ⏱️ Timestamp kahan hai?

Har row ke andar:

```text
[1, 2, 3]
 ↑  ↑  ↑
 t1 t2 t3
```

👉 Positions hi timestamp hain:

* 1 → time step 1
* 2 → time step 2
* 3 → time step 3

---

👉 timesteps = 3

---

### 🔹 Features

**Riya:**
Har step pe kya hai?

```text
sirf ek number
```

👉 features = 1

---

### 🔹 Samples

**Riya:**
Total sequences kitne hain?

👉 4

---

### 🔥 Final Shape

```text
(4, 3, 1)
```

## 🔄 Scene 14 — Reshape

```python
# reshape to (samples, timesteps, features)
X = X.reshape((4, 3, 1))

print(X.shape)  # (4, 3, 1)
```

---

## 🏗️ Scene 15 — Model Build

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense

model = Sequential()  # layer by layer model
```

---

### 🔹 RNN Layer

```python
model.add(SimpleRNN(
    10,                # 10 memory units (10 neurons jo memory store karte hain)
    activation='relu', # activation function
    input_shape=(3,1)  # (timesteps, features)
))
```

---

**Aman:**
10 units kya karte hain?

**Riya:**
Ye sequence ka pattern yaad rakhte hain 🧠

---

### 🔹 Output Layer

```python
model.add(Dense(1))  # ek number predict karega
```

---

## ⚙️ Scene 16 — Compile

```python
model.compile(
    optimizer='adam',  # weights update karega
    loss='mse'         # error measure karega
)
```

---

## 🏋️ Scene 17 — Training

```python
model.fit(
    X,
    y,
    epochs=200,   # 200 baar seekhega
    verbose=0     # logs hide
)
```

## 🧪 Scene 18 — Testing
