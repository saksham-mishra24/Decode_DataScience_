## 💻 Code

```python id="rnn4_1"
import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense
```

---

### 📊 Dummy Data

```python id="rnn4_2"
# 3 sequences (samples)
X = np.array([
    [1, 2, 3],  # sequence 1
    [2, 3, 4],  # sequence 2
    [3, 4, 5]   # sequence 3
])

# Output (0 ya 1 → classification)
y = np.array([1, 0, 1])
```

---

### 🔄 Reshape

```python id="rnn4_3"
# convert to (samples, timesteps, features)
X = X.reshape((X.shape[0], X.shape[1], 1))
```

---

### 🏗️ Model

```python id="rnn4_4"
model = Sequential()

model.add(SimpleRNN(
    8,                 # 8 memory units
    input_shape=(3,1)  # 3 steps, 1 value per step
))

# output layer
model.add(Dense(
    1,                 # single output
    activation='sigmoid'  # probability (0–1)
))
```

---

**Aman:**
`return_sequences=True` nahi lagaya?

---

**Riya:**
Good catch 😎

👉 kyuki hume sirf **final output** chahiye
👉 beech ke outputs ka use nahi hai
