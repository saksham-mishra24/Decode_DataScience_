## 🔥 Scene 11 — Full Example

```python id="rnn5_6"
import numpy as np
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Masking, SimpleRNN, Dense

# raw sequences (different lengths)
sequences = [
    [1, 2, 3],
    [4, 5],
    [6]
]

# targets (dummy outputs)
y = np.array([1, 2, 3])

# step 1: padding (equal length)
X = pad_sequences(sequences, padding='post')

# step 2: reshape for RNN (samples, timesteps, features)
X = X.reshape((X.shape[0], X.shape[1], 1))

# step 3: model
model = Sequential()

# masking layer → ignore zeros
model.add(Masking(mask_value=0, input_shape=(3,1)))

# RNN layer
model.add(SimpleRNN(8))

# output layer
model.add(Dense(1))

# compile
model.compile(
    optimizer='adam',
    loss='mse'
)

# train
model.fit(
    X,
    y,
    epochs=100,
    verbose=0
)

print("Training complete")
```
