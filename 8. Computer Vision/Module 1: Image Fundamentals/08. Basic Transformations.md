# 🔄 Scene 4 — Transformation #1: Resize

## 🎬 Entry

**Riya:** Sabse common:

---

## 🔥 Scene 5 — Why?

👉 Model ko fixed size chahiye
👉 Processing fast hoti hai

---

## ⚙️ Code

```python

img = cv2.imread("image.jpg")

resized = cv2.resize(img, (224, 224))
```

# 🔄 Scene 9 — Transformation #3: Rotate

## 🎬 Entry

👉 Image ghumana 🔄

---

## ⚙️ Code

```python
(h, w) = img.shape[:2]

center = (w//2, h//2)

M = cv2.getRotationMatrix2D(center, 45, 1)

rotated = cv2.warpAffine(img, M, (w, h))
```

# 🔄 Scene 12 — Transformation #5: Translation

## 🎬 Entry

👉 Image ko left-right / up-down shift karna

---

## ⚙️ Code

```python
import numpy as np

M = np.float32([[1, 0, 50], [0, 1, 30]])

shifted = cv2.warpAffine(img, M, (img.shape[1], img.shape[0]))
```
