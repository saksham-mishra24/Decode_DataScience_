## 🧠 Scene 7 — RGB kya hai?

👉 RGB = **Red + Green + Blue**

👉 Har pixel = 3 values

Format:

```python
(R, G, B)
```

---

## 🔥 Scene 8 — Examples

```python
(255, 0, 0)   → Red 🔴
(0, 255, 0)   → Green 🟢
(0, 0, 255)   → Blue 🔵
(255,255,255) → White ⚪
(0,0,0)       → Black ⚫
```

## ⚔️ Scene 15 — Grayscale vs RGB

| Feature   | Grayscale | RGB     |
| --------- | --------- | ------- |
| Channels  | 1         | 3       |
| Data size | Low       | High    |
| Speed     | Fast ⚡    | Slow 🐢 |
| Info      | Less      | More    |
