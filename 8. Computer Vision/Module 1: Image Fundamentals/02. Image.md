## 🧠 Scene 8 — RGB samajh

**Riya:** Har pixel ke paas 3 values hoti hain:

👉 (R, G, B)

Example:

```
(255, 0, 0) → Red
(0, 255, 0) → Green
(0, 0, 255) → Blue
(255,255,255) → White
(0,0,0) → Black
```

## ⚙️ Scene 16 — Code ka first step

**Riya:** Chal thoda code dekhte hain 😎

```python
import numpy as np

# grayscale image (3x3)
img = np.array([
    [0, 50, 200],
    [30, 255, 100],
    [10, 80, 60]
])

print(img.shape)  # (3, 3)
```

---

## 🎨 Scene 17 — RGB image

```python
# color image (2x2)
img = np.array([
    [[255,0,0], [0,255,0]],
    [[0,0,255], [255,255,0]]
])

print(img.shape)  # (2, 2, 3)
```
