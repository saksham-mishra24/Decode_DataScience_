# 📚 Overview

**Computer Vision Mastery** is a structured, real-world focused repository designed to take you from understanding images to building **production-ready vision systems**.

It covers:

* Image Fundamentals & Processing
* Classical Computer Vision
* Geometry & Camera Systems
* Machine Learning for Vision
* Deep Learning (CNNs → Transformers)
* Object Detection & Segmentation
* Video & Motion Analysis
* Modern Vision Models
* Deployment & Real-World Systems

This repository is designed as a **complete Computer Vision learning ecosystem**.

---

## Module 1: Image Fundamentals

* Images as matrices
* Image storage formats
* Color spaces (RGB, HSV, LAB)
* Basic transformations

## Module 2: Image Processing

* Filtering & smoothing
* Noise handling
* Edge detection
* Thresholding
* Histograms & equalization
* Morphological operations
* Contours & shapes
* Image segmentation

---

## Module 3: Classical Computer Vision

* Feature detection (corners, keypoints)
* Feature descriptors
* Feature matching
* Template matching
* HOG features
* Classical object detection

---

## Module 4: Geometry in Vision

* Image transformations
* Homography
* Camera models
* Intrinsic & extrinsic parameters
* Camera calibration
* Stereo vision
* Depth estimation

---

## Module 5: Machine Learning for Vision

* Image classification (traditional ML)
* SVM, KNN, Decision Trees
* PCA (Dimensionality Reduction)
* Bag of Visual Words

---

## Module 6: Deep Learning for Vision

* CNN fundamentals
* Convolution, kernels, feature maps
* Pooling layers
* Training deep models
* Regularization techniques
* CNN architectures (LeNet → ResNet)

---

## Module 7: Vision Tasks

* Image classification
* Object detection (R-CNN → YOLO)
* Semantic & instance segmentation
* Pose estimation
* Face recognition
* OCR

## Module 8: Video Vision

* Action recognition

## Module 9: Modern Computer Vision

# 🚀 Getting Started

### Prerequisites

* Python 3.9+
* Basic Linear Algebra
* Basic Probability & Statistics
* Git

### Installation

```bash
git clone https://github.com/yourusername/computer-vision-mastery.git
cd computer-vision-mastery

python -m venv venv
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows

pip install -r requirements.txt
```
